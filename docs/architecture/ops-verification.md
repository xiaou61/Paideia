# 运维核查清单（未核实项）

本清单列出**本轮未实际核实、且需要线上授权**的运维事实。它们不是"做完了"，而是"必须由有权限的人另行确认"。任何人不得把这里当成已验证结论。

核对方式：逐项在服务器/云控制台执行右列命令或操作，把结果与结论登记到 `.agent/changes/WORK-<编号>/` 对应验收记录；核实前保持状态「未核实」。

| # | 事项 | 当前状态 | 核对方式 | 通过判据 |
| --- | --- | --- | --- | --- |
| 1 | 数据库备份的**异地性** | 未核实 | 查看 `deploy/ops/paideia-backup.sh` 的实际落地位置与保留策略；确认备份是否只在本机 | 至少一份备份在**异机/异地**（对象存储或另一台主机），不是仅同机磁盘 |
| 2 | 备份**可恢复性**（隔离恢复演练） | 未核实 | 在隔离实例上从最近备份恢复一次，比对关键表行数与时间点 | 能在隔离库成功恢复，且不触碰生产；记录恢复耗时 |
| 3 | 对外 **HTTPS/TLS** | 未核实 | 检查是否仍以纯 HTTP 对外监听；确认反代证书与跳转 | 外部访问走 HTTPS，HTTP 跳转 HTTPS，证书有效期正常 |
| 4 | 运维端点**暴露面** | 未核实 | 确认 `/actuator/**` 是否经反代暴露到公网；核对 loopback 信任假设 | 生产 `/actuator/**` 不对公网开放（代理拒绝或独立监听），指标仅内网可达 |

## 边界

- 本清单不改任何线上配置；核实与变更都需单独授权。
- 「未核实」不等于「有问题」，也不等于「没问题」——只是本仓库没有证据。
- 与发布回滚相关的代码边界见 [`03-deployment.md`](03-deployment.md) 的「发布失败的回滚边界」。
