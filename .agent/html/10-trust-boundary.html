10 / 安全

谁能不登录访问什么

这张图回答：哪些端点不需要身份？「UUID 即凭据」这种做法的边界在哪？为什么规则的书写顺序比规则内容更容易出事？

先看一个具体场景

你把一篇笔记设成「可分享」，把链接发给朋友。他没登录，点开就能看——因为链接里那串随机 ID 就是你给出去的钥匙。

你把链接末尾改一个字符，立刻变成 404。这就是「UUID 即凭据」：没法猜、不用登录，但一旦泄露就等于把门打开了。

它内部是怎么做到的

「匿名」「登录」「管理员」「只允许本机」是四种不同的信任级别，不是三种。最容易被忽略的是第四种——它不属于免鉴权，而是「连网都进不来」。

免鉴权端点与它们各自的凭据

路径为什么必须免鉴权靠什么把关
/actuator/health探活只返回状态，不含数据
/api/v1/auth/**登录发生在有身份之前图形验证码、失败限流、邮件验证码
GET /api/v1/knowledge/files/**<img> 不携带 Authorization 头，要求登录则图片全裂UUID 不可枚举；只放行 GET
GET /api/v1/public/shares/**分享给未登录的人看UUID；只含标题与正文，不含作者与学习痕迹
GET /、/assets/**、/admin/**、PWA 清单与 sw.js登录页要先能加载；Service Worker 注册是匿名请求纯静态文件，不含数据
/api/v1/ops/grafana/**iframe 导航拿不到 Bearer，Grafana 是 SPAGrafana 自己的登录（匿名已关闭）

规则按顺序判定，第一条匹配就停

这一层最危险的不是规则内容，是书写顺序。写反了不报错、不告警；如果测试没覆盖，就会一直越权。

真缺陷长什么样：/api/v1/sandbox/admin/** 一度写在 /api/v1/sandbox/**（要求已登录）之后，于是任何登录用户都能下架别人的数据集、看到全部举报。它不报错，是合并时由 ApiContractTest 抓到的。

注销：没有外键，所以有一份手写的表清单

这是「信任边界」里最容易被忽略的一段：数据删得干不干净。全库几乎没有外键，级联删除不存在，所以注销靠各模块自己维护的表清单，一张一张删。

账号消失
清单漏一张：数据还在，没有报错，也没有测试会红

新增一张带 user_id 的表，必须同时把它加进清单。这条不能靠自动化发现——这正是「少外键」这个选择的真实代价。匿名化的部分（比如公开分享页）单独处理，不能一删了之。

设计取舍：UUID 即凭据，边界在哪

  • 为什么不用登录：分享的本意就是「发给没账号的人看」；附件是 <img> 请求，浏览器不会带令牌。要求登录等于这两个功能直接不可用。
  • 代价一：链接泄露 = 权限泄露。所以 id 必须是 UUID（不可枚举），且只放行 GET——把 POST 一起放行等于开了匿名写入口。
  • 代价二：不能撤销单个链接。目前的撤销是「关掉分享」，整条链接失效。要做到单链接吊销，得再加一张令牌表。
  • 代价三：审计不到「谁看的」。匿名访问没有身份，只能记访问量。
  • MCP 是一条平行通道。个人访问令牌由独立过滤器识别，权限按工具组切分，不走 JWT。改工具清单时要同时想「这个令牌能不能调它」。
  • 积分闸不是授权闸。它判断「够不够钱」，位置在 Controller 之后，返回 402。写进 Security 配置会得到错误语义（管理员也会没钱）。

读图要点

  • 路径命名有纪律：管理端接口一律 /api/v1/<模块>/admin/**。/api/v1/admin/<模块> 这种写法不匹配任何既有规则，会直接落到兜底——看起来加了 admin 其实谁都能调。
  • 放行读 ≠ 放行写。两处免鉴权的读都限定了 GET；写入口走的是另一条要登录的路。
  • 前端守卫从来不是边界。路由守卫只决定显示什么；能不能做，只由 /api/** 上的规则决定。
  • 401 与 403 的区别要在界面上体现。401 应该自动换令牌重试；403 重试多少次都一样。

代码在哪

  • backend/paideia-security/…/SecurityConfiguration.java — 全部规则、顺序，以及每条「必须排在谁之前」的注释
  • backend/paideia-security/…/LocalOnlyAuthorizationManager.java — 「只允许回环」的判定
  • backend/paideia-mcp/…/security/PatAuthenticationFilter.java、McpSecurityConfiguration.java — 令牌通道
  • backend/paideia-note/…/share/ShareService.java — share_id 为什么是 UUID
  • backend/paideia-ai/…/billing/CreditService.java — 业务闸（402）
  • ApiContractTest — 抓过越权缺陷的那个测试
