# 需求

## 功能

- **REQ-001**：在「造一个自己的数据集」弹窗里点「让 AI 设计」，关闭弹窗、打开助手面板，并在对话区出现
  一张向导卡：三组选项（练什么 / 几张表 / 多少行），每组默认选中第一项。用户不需要手输提示词。
- **REQ-002**：点向导卡的「生成」把三组已选项拼成一条消息**自动发送**；消息里明确"我已经选好了，
  直接用 `planner_build_dataset` 生成，不要再问我问题"。不点「生成」就不发送。
- **REQ-003**：SQL 工作台的助手回答（含 sql 代码块）提供三个动作：
  「插入」= 追加到编辑器现有内容之后；「继续编辑」= 替换编辑器全文并聚焦；「存为数据集」保持现状。
- **REQ-004**：其他 `ask()` 入口（看 SQL 问题、按数据集出题等）语义不变——仍只预填输入框。

## 验收标准

- **AC-001**：点「让 AI 设计」后，数据集弹窗消失、助手面板打开、`assistant-guide` 可见；输入框为空（不再预填长提示词）。
- **AC-002**：点「生成」后对话里出现一条 user 消息，内容包含三组选择值；未点「生成」前没有任何发送。
- **AC-003**：回答含 sql 代码块时显示「插入编辑器」与「继续编辑」；点「插入」后编辑器 = 原内容 + 空行 + SQL；
  点「继续编辑」后编辑器 = SQL 且获得焦点。
- **AC-004**：其他 `ask()` 入口点击后仍只在输入框预填（不发送）。
- **AC-005**：回答里没有 sql 代码块时，两个动作给出明确提示（沿用 `extractSqlBlock` 的既有行为）。

## 非目标

- 向导选项的文案与模型内容质量；不做"按当前数据集动态生成选项"。
- 不做持久化（向导卡不进会话历史，关掉面板即消失）。
