# SQL 数据集 AI 引导式生成

## 背景

「造一个自己的数据集 → 让 AI 设计」现在只把一句长提示词预填进助手输入框：用户还要自己按发送，
模型先回一大段文字反问三件事，来回两轮才可能给出 SQL。2026-11-03 用户反馈：点击后就该进入对话、
第一轮直接给可点的选项，选完出 SQL，SQL 之后能选「插入」或「继续编辑」。

## 用户裁决（2026-11-03）

- 选项由**页面本地向导卡**产生，不让模型输出选项块——省一轮等待，也不会因模型格式漂移退化成文字。
- SQL 出来后：**插入 = 追加到编辑器**；**继续编辑 = 替换编辑器全文并聚焦**。
- 其他 `ask()` 入口保持"只预填不发送"（发送等于替用户花钱，那条纪律不变）。

## 不做什么

- 不改后端、不加工具、不新增 SSE 事件类型。
- 不做"多轮让 AI 继续改"的专门入口（用户可在输入框自己说）。
- 不改数据集弹窗的保存链路（仍由用户点「确认保存」）。
