# 需求

## 目标

学习者端不再有通用 AI 助手面板；原先依赖它的能力要么有独立入口，要么删除。
后端接口与数据一律保留。

## 候选需求

- **REQ-001**：移除 `AssistantShell` 与全局对话入口（页头按钮、Ctrl+J、`ask()` 跳转）。
- **REQ-002**：精简（AI 摘要）在条目页提供「生成摘要」按钮与结果卡片；不再需要打开面板。
- **REQ-003**：记忆与积分各有一个独立页面（设置下），承载开关、候选确认、余额与流水。
- **REQ-004**：删除八处"预填一句话"的「问 AI」按钮（或以专用小流程替代，取决于裁决 2）。
- **REQ-005**：管理端保留裁决 3 选定的一项，其余不变。

## 验收标准

- **AC-001**：学习者端任意页面都不再出现助手面板与 `ask()` 触发的跳转。
- **AC-002**：条目页能生成/查看摘要；失败有可见原因。
- **AC-003**：设置页能开关记忆、确认/拒绝候选、查看积分流水。
- **AC-004**：原来八处按钮不再存在，或替换后的流程可用（取决于裁决 2）。
- **AC-005**：后端 `memories` / `credits` / `summaries` / `conversations` 接口与数据原样保留。

## 非目标

- 不迁移/删除已有会话、记忆、积分数据。
