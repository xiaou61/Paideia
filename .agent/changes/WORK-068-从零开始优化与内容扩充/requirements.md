# 需求

## 目标

围绕「从零开始」的地图与阅读体验完成 18 项用户视角优化，并补齐前端、数据分析、Web 安全、测试、Python、Linux、Docker 等内容线，使学习者从入口到实战都有可走的路径。

## 验收标准

各 REQ 下的 `AC-001..AC-010` 即本项验收标准；内容线以线上导入结果与练习盘点脚本为准。

## REQ-001 选读默认折叠

- 选读区默认收起，标题行仍显示条数、关卡数、已通关数；
- 用原生 `details/summary`，键盘可操作；
- 核心、进阶保持展开。

**AC-001** `/learn` 首屏不需要滚动就能看见推荐卡与核心区；点「展开」后选读卡片出现。

## REQ-002 轨道卡显示下一关

- 未开始的卡显示关数；进行中的卡显示"下一关：标题"。

**AC-002** 有进度的轨道卡底部出现具体关卡名，不再是"—"。

## REQ-003 岗位总览行

- 岗位选择器下显示"核心 + 进阶共 N 关 · 已通关 M 关（P%）"。

**AC-003** 切换岗位后数字随之变化；选读不计入。

## REQ-004「继续上次」只在有进度时出现

**AC-004** 没有任何已开始轨道时，页面不渲染 `learn-continue`。

## REQ-005 轨道页章节跳转

- 章节数 ≥ 2 时显示 chip 行，点击滚到对应章节。

**AC-005** 37 关的 Java 线点击第 3 章，视口移动到该章节标题。

## REQ-006 轨道页到期复习提示

- 只统计本轨道内的到期项；有则显示入口，链到 `/review`。

**AC-006** 有到期项时出现 `track-due-reviews`，数字与复习列表一致（按本线过滤）。

## REQ-007 只看未通关

- 开关只过滤，不重排；与难度筛选叠加生效。

**AC-007** 打开后已通关关卡从地图消失，关闭后恢复。

## REQ-008 条目页关卡定位与通关状态

- 从地图进入时显示「线路名 · 第 N/M 关」；
- 显示已通关/未通关。

**AC-008** 直接打开同一条目（无来源 state）不显示"第 N/M 关"。

## REQ-009 练习块盘点

- 脚本按线汇总关卡数、练习块数、零练习篇数，可列出清单；
- 顺带校验 quiz JSON 是否合法。

**AC-009** `node scripts/check-practice-coverage.mjs` 输出 34 条线；`--missing` 为空。

## REQ-010 内容线

- `frontend-from-zero`：12 关 + 总览，每关至少一道 quiz；
- 岗位映射把前端岗位指向它，并置 `available: true`；
- 其余线（data-analysis / web-security / testing-from-zero / 三条实战）按任务表推进。

**AC-010** 导入后 `/learn` 前端岗位核心区出现这条线；`/learn/frontend-from-zero` 有 12 关。
