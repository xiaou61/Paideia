# 数据集 AI 生成改为弹窗向导

## 背景

WORK-063 把「让 AI 设计」接进了助手对话：选项卡在面板里，点生成后模型回一段长文 + SQL。
用户 2026-11-03 实测反馈"一点也不智能、很不好用"——聊天的人格默认会讲解，而数据集是产物不是对话。

## 用户裁决（2026-11-03）

- 改成**弹窗里的三步向导**：选四项 → 生成 → SQL 回填「写 SQL」，改完再保存；不再开助手。
- 表名不加用户标识：每个数据集在自己的临时库里跑，不存在跨数据集冲突；会重名的只是数据集名字。

## 不做什么

- 不改助手聊天本身（问 SQL 怎么写仍然走聊天，「插入编辑器 / 继续编辑」保留）。
- 不为数据集名字做重名校验（列表里靠名字认，重名只是观感问题）。
- 不加"预览页/图表"，SQL 框本身就是预览。
