# 需求

- **REQ-001**：复习交卷后的每道错题提供「AI 讲讲这道错题」，返回 120 字内的解释；结果不落库。
- **REQ-002**：学习记录页提供「让 AI 排一下今天做什么」，返回 3 条、每条 40 字内且引用具体数字。
- **REQ-003**：知识图谱的概念详情提供「AI 用大白话讲讲」，返回 150 字内的解释 + 最小例子。
- **REQ-004**：笔记页提供「AI 提炼要点」，返回 3–5 条、只保留原文事实。
- **REQ-005**：条目页提供「AI 出一道题」，返回 4 选项单选题 + 正确项 + 一句话解析；作答后在弹窗内立即反馈。
- **REQ-006**：所有调用走平台凭据；先预留再按用量结算，失败全额退款；入参全部做长度与形状校验。

## 验收标准

- **AC-001**：五个端点匿名 401；合法请求在未配置 AI 时返回可读 400；非法入参返回 400。
- **AC-002**：前端五处入口都能打开并渲染结果；失败有可见提示，不影响页面其它部分。
- **AC-003**：复习结果的 `answer` 字段由服务端下发（交卷后才可见），前端据此传 `answer`。
- **AC-004**：模型返回非 JSON / 条数越界时按失败处理（退款），不返回半截结果。
