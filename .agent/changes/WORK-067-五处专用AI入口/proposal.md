# 五处专用 AI 入口

## 背景

WORK-066 移除了通用助手。用户随即问"页面上哪里还能加 AI"，并批准把这五处补上——每一处都是
**有明确输入、明确输出的小动作**，不是聊天：

1. 复习结果里的错题讲解（题面 + 你选的 + 正确项 → 为什么错）；
2. 学习记录页的「下一步做什么」（四块记录 → 三条）；
3. 知识图谱点概念 → 大白话解释 + 最小例子；
4. 笔记页 → 提炼 3–5 个要点；
5. 条目页 → 按正文出一道单选题（当场作答看解析）。

## 用户裁决（2026-11-04）

直接批准执行。范围就是这五处，不加第六处。

## 约束

- **不落库**：没有历史、没有"再次查看"，结果只属于这一次点击。
- **点击才花钱**：五个入口都不在页面加载时自动调用。
- 复用现有 AI 基础设施：平台凭据、预留-结算、退款、提示词版本号；不新增依赖。
