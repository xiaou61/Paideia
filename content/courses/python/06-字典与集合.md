# 06 · 字典与集合

## 这一课你要会

- 用字典按"名字"取数据，知道取不到时该用 `get` 还是直接下标；
- 用集合去重、做交并差；
- 知道为什么列表不能当字典键，元组可以。

## 为什么

列表靠位置找东西：`items[3]`。但你真正想知道的是"这个人的成绩是多少"，而不是"第 3 个元素是谁"。

字典解决这个问题：**键 → 值**。它也是 Python 里除列表外最常用的数据结构——JSON、配置、缓存表、计数器，全是字典。

## 讲解

### 取不到时会发生什么

```text
user["age"]          # 键不存在 → KeyError，程序崩
user.get("age")      # 键不存在 → None，不崩
user.get("age", 0)   # 键不存在 → 0
```

**先问自己"这个键必须存在吗"**：必须存在就直接下标（崩得早比悄悄给个默认值更好查）；可能不存在用 `get`。

### 增改删

```text
scores["小林"] = 90       # 有则改，无则加
del scores["小林"]
scores.pop("小林", None)  # 取走；不存在时返回默认值而不是报错
```

### 遍历字典

- `for key in d:` 遍历键；
- `for key, value in d.items():` 同时拿键值；
- `d.keys()`、`d.values()`、`d.items()` 都是视图，不是列表（要列表就 `list(...)`）。

遍历时**不能增删键**，会抛 `RuntimeError: dictionary changed size during iteration`。要筛掉一些键，就构建新字典。

### 集合：只关心"有没有"

集合无序、不重复、查找很快。

```text
tags = {"python", "后端", "python"}
print(tags)            # {'python', '后端'} —— 重复的没了
a & b   # 交集
a | b   # 并集
a - b   # 差集
```

去重最常用：`unique = list(set(items))`。**注意这会打乱顺序**；要保留原顺序且去重，用 `dict.fromkeys(items)`（字典保持插入顺序，这是 Python 3.7 起的语言保证）。

### 为什么列表不能当键

字典和集合靠**哈希**定位。可哈希意味着"这个对象的内容不会变"——列表能改，改完之后哈希值就变了，之前存的位置就找不回来了。元组不可变，所以可以。

## 常见误区

### 误区：遍历字典时可以顺手删掉某些键

**你以为**：`for k in d: if 条件: del d[k]` 是常见写法。
**其实**：会抛 `RuntimeError: dictionary changed size during iteration`。
**怎么验证**：写三行代码试一次，看报错原文。

### 误区：`set()` 去重后顺序和原来一样

**你以为**：去重只删重复，不动顺序。
**其实**：集合无序。要保序用 `dict.fromkeys`。

### 误区：`d.get(k)` 和 `d[k]` 只是写法不同

**你以为**：随便用哪个。
**其实**：前者在键不存在时返回 `None`（错误被藏起来），后者当场报错。**该报错的地方让它报错**。

## 小结

字典按键找值，键必须可哈希。`get` 与下标的选择，取决于"这个键是否必须存在"。集合擅长去重与交并差，但不保序。遍历时不要改容器大小。
