# 02 · 运算与条件

## 这一课你要会

- 分清 `/`、`//`、`%` 各自干什么；
- 知道为什么 `0.1 + 0.2 == 0.3` 是 `False`，以及该怎么比较小数；
- 用 `if / elif / else` 让程序按条件走不同分支。

## 为什么

程序真正开始"有用"，是从它能**根据输入走不同的路**开始的。而走不同路要先会判断，判断要先会算。

这一课有两个坑，几乎所有初学者都会掉进去：整数除法和浮点数比较。它们不会报错，只会**悄悄给出你以为不对的结果**——这比报错更难查。

## 讲解

### 三种除法

| 写法 | 名字 | `7` 和 `2` 的结果 | 说明 |
| --- | --- | --- | --- |
| `7 / 2` | 真除法 | `3.5` | 永远返回小数 |
| `7 // 2` | 整除 | `3` | 只要整数部分，向下取整 |
| `7 % 2` | 取余 | `1` | 7 除以 2 余 1 |

`//` 是**向下**取整，不是"截断小数"：`-7 // 2` 是 `-4`，不是 `-3`。这个区别在做负数分页、坐标换算时会让结果差一。

### 浮点数不是精确的

计算机用二进制存小数，而 `0.1` 在二进制里是无限循环小数——就像 `1/3` 在十进制里是 `0.333…`。存不下，只能存一个近似值。

两个近似值相加，误差会露出来：`0.1 + 0.2` 得到 `0.30000000000000004`。

**所以小数之间不要用 `==`**。要比较就用一个容差：

```text
abs(a - b) < 1e-9
```

Python 标准库里有 `math.isclose(a, b)`，直接用它更清楚。

### 布尔值与真值

比较运算（`>`、`<`、`==`、`!=`、`>=`、`<=`）的结果是 `True` 或 `False`。

`if` 后面跟的不一定非要是比较：Python 把空值当作"假"——`0`、`""`、`[]`、`{}`、`None` 都是假，其它是假。用 `if items:` 判断列表非空，是惯用写法。

### 组合条件

- `and`：两边都真才真；
- `or`：有一边真就真；
- `not`：取反。

`and` 和 `or` 会**短路**：`if user and user.name:` 里，如果 `user` 是 `None`，右边根本不会执行，所以不会抛 `AttributeError`。这是很常用的保护写法。

### 跑一遍

<!-- run -->
```python
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(-7 // 2)

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)

import math
print(math.isclose(0.1 + 0.2, 0.3))

score = 78
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 两个容易写反的地方

**`=` 是赋值，`==` 是比较。** 写 `if x = 1:` 在 Python 里直接语法错误（这是好事，Java 里同样的错会静默通过）。

**`elif` 是有顺序的。** 上面如果先写 `score >= 60` 再写 `score >= 90`，90 分也会落进"及格"——因为第一个满足的条件就跳出了。

## 常见误区

### 误区：`is` 和 `==` 差不多，都能比较值

**你以为**：两个变量内容一样，用哪个都行。
**其实**：`is` 比的是"是不是同一个对象"，`==` 比的才是值。小整数和短字符串有时恰好是同一个对象，那是实现细节，**不能依赖**。

**怎么验证**：`a = 1000; b = 1000; print(a is b, a == b)`，多数环境会得到 `False True`。

### 误区：`17 / 3` 得 5

**你以为**：除法默认就是整除。
**其实**：`/` 永远给小数，`//` 才是整除。想要 5 就写 `17 // 3`。

### 误区：浮点数比较可以放心用 `==`

**你以为**：只要两边"应该相等"就行。
**其实**：只要有运算，误差就可能出现。用 `math.isclose`，或者把金额换成"分"用整数算。

## 小结

`/` 给小数，`//` 给向下取整的整数，`%` 给余数。小数不要用 `==`。条件按顺序求值，所以从最严格的条件开始写。
