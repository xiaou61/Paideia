# 01 · 环境与第一行代码

## 这一课你要会

- 在自己的电脑上把一段 Python 代码跑起来，看到输出；
- 知道变量是什么，以及 `"18"` 和 `18` 不是一回事；
- 能读懂最简单的报错，知道它指向哪一行。

## 为什么

编程这件事的门槛不在语法，在**第一行**。装好环境、跑通一次、看到自己写的话被打印出来，后面的东西才有落点。

很多人在这里放弃，不是因为难，而是因为网上教程默认你已经会了：默认你会开终端、知道什么是"路径"、看得懂 `command not found`。这一课把这些默认全部拆开。

## 讲解

### 三种跑法

1. **交互模式**：终端里输入 `python`（macOS/Linux 可能是 `python3`），出现 `>>>` 就可以一行一行敲。适合试一小段。
2. **文件模式**：新建 `hello.py`，写完在终端里 `python hello.py`。**这是本课及以后所有例子的方式。**
3. **编辑器里点运行**：VS Code 装 Python 扩展后可以直接点右上角的三角形。它背后做的仍然是第 2 种。

三种跑法没有高下，但**报错的位置**只有文件模式最清楚：它会告诉你第几行。

### 变量不是一个盒子

`name = "小林"` 做的事是：造一个字符串对象，然后让名字 `name` 指向它。名字可以改指向别的东西，但类型是跟着**值**走的，不跟着名字走。

所以 Python 里没有"声明一个整数变量"这种说法，直接赋值就行。

### 类型为什么重要

`"18"` 是文本，`18` 是数字。文本不能直接做加法：

```text
"18" + 1   → 报错
18 + 1     → 19
```

这不是 Python 啰嗦，而是它在替你挡住"把年龄当字符串拼进句子、然后又想拿它算钱"这类错误。

### 跑一遍

下面这段可以直接运行。注意三个 `print` 的输出顺序，以及 `type()` 告诉你的事情。

<!-- run -->
```python
name = "小林"
age = 18

print("你好，" + name)
print(age)
print(type(age))
print(type("18"))
print(age + 1)
```
```text
你好，小林
18
<class 'int'>
<class 'str'>
19
```

把 `age` 改成 `"18"` 再运行，最后一行会变成 `181`——因为两个字符串相加是拼接，不是算术。**这就是类型在起作用。**

### 读报错

报错分两半：上面是**类型和原因**，下面是**位置**。

```text
Traceback (most recent call last):
  File "hello.py", line 3, in <module>
    print("你好，" + age)
TypeError: can only concatenate str (not "int") to str
```

翻译过来：第 3 行，想把字符串和整数拼在一起，不允许。修法有两种：`str(age)` 把它转成文本，或者用下一课要讲的 f-string。

## 常见误区

### 误区：Python 变量要先声明类型

**你以为**：得像 Java 那样写 `int age = 18`。
**其实**：直接 `age = 18`，类型跟着值走。想确认类型就用 `type()`。
**怎么验证**：`age = 18` 之后打印 `type(age)`，再改成 `age = "18"` 打印一次，两次结果不同。

### 误区：单引号和双引号有功能区别

**你以为**：`'abc'` 和 `"abc"` 不一样。
**其实**：完全一样，选哪个只是"里面要不要出现同种引号"的方便问题。

### 误区：print 会把引号一起打出来

**你以为**：`print("你好")` 会输出 `"你好"`。
**其实**：引号只是告诉解释器"这是文本"，不进入内容。屏幕上只有 `你好`。

## 小结

跑起来的方式有三种，但只有文件模式给的错误位置最清楚。变量是名字指向值，类型跟着值走。看到 `TypeError` 先看最后一行。
