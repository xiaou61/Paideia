# 03 · 循环

## 这一课你要会

- 用 `for ... in range(...)` 重复固定次数、用 `while` 重复到条件不成立；
- 知道 `break` 和 `continue` 的区别；
- 知道为什么"一边遍历一边删"是错的，以及正确写法。

## 为什么

没有循环，程序只能做一次事。有了循环，才能处理"一百条记录""一直到用户输入 q 为止"。

循环也是新手第一个真正卡住的地方：**不是语法不会，而是不知道什么时候停**。所以这一课的重点在边界——起点包不包含、终点包不包含、什么时候跳出。

## 讲解

### `range` 的右端是开区间

`range(1, 4)` 产出 `1, 2, 3`，**没有 4**。

这条规则只有一个好处：`range(len(items))` 正好覆盖所有下标，不需要减一。记住"左闭右开"，后面所有切片、字符串位置都用同一套约定。

三种写法：

| 写法 | 结果 |
| --- | --- |
| `range(3)` | 0, 1, 2 |
| `range(1, 4)` | 1, 2, 3 |
| `range(0, 10, 3)` | 0, 3, 6, 9 |

### `for` 和 `while` 怎么选

- **次数确定**用 `for`：遍历列表、遍历文件行、跑固定轮数；
- **次数不确定、靠条件停**用 `while`：直到用户输入正确、直到队列为空。

`while` 有一个人人都遇过的风险：条件永远不成立，程序卡死。写 `while` 时，先问自己"哪个动作会让条件最终变假"。

### `break` 与 `continue`

- `break`：立刻结束整个循环；
- `continue`：跳过本轮剩下的语句，直接进入下一轮。

它们都能用其它方式改写，但用对了能让嵌套少一层。**代价是**读代码的人要跳到循环外才能确定"什么时候结束"——所以只在"提前退出"确实更清楚的时候用。

### 遍历时不要改动正在遍历的容器

```text
for item in items:
    if item < 0:
        items.remove(item)   # 危险
```

原因是列表的"下一个位置"是按索引推进的：删掉一个元素，后面的元素整体前移，于是**下一个元素被跳过**。更糟的是它不报错，看起来只是"少删了一个"。

### 跑一遍

<!-- run -->
```python
total = 0
for i in range(1, 4):
    total = total + i
print(total)

countdown = 3
while countdown > 0:
    print(countdown)
    countdown = countdown - 1
print("结束")

numbers = [1, -2, 3, -4]
kept = []
for number in numbers:
    if number < 0:
        continue
    kept.append(number)
print(kept)

for number in numbers:
    if number > 2:
        print("第一个大于 2 的是", number)
        break
```

```text
[1, 3]

```

### 缩进就是语法

Python 用缩进表示"哪些语句属于同一个块"。缩进不一致不是排版问题，是语法错误（`IndentationError`），或者更隐蔽的：逻辑错误。

**统一用 4 个空格**，不要用 Tab。编辑器里把"按 Tab 插入空格"打开。

## 常见误区

### 误区：缩进只是排版，空格多少无所谓

**你以为**：只要看着对齐就行。
**其实**：缩进参与语法，决定哪些语句属于同一个块。混用 Tab 与空格还会触发 `TabError`。
**怎么验证**：把循环体里某一行少缩进一格再运行，看报错位置。

### 误区：`while` 可以随便写，反正有解释器兜着

**你以为**：条件写错了顶多是结果不对。
**其实**：条件永远为真会**卡死**，只能强制中断。写 `while` 时必须能指出"哪一步让条件变假"。

### 误区：`for i in range(len(items))` 是最标准的写法

**你以为**：必须先拿下标才能遍历。
**其实**：直接 `for item in items:` 更清楚。需要下标时用 `enumerate(items)`。

## 小结

`range` 左闭右开，这是全 Python 统一的约定。`for` 用于确定的次数，`while` 用于条件驱动，写 `while` 先找退出条件。遍历时不改原容器。
