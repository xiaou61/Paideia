# 11 · 继承与多态

## 这一课你要会

- 写一个子类，用 `super()` 复用父类的初始化；
- 说清"多态"到底解决了什么问题；
- 知道什么时候**不该**用继承，改用组合。

## 为什么

继承解决的是"两个东西大部分相同、少数不同"。多态解决的是"同一个调用，不同对象做出不同反应"。

这两个概念被讲得过于玄。这一课只留最有用的部分：**能说出来一次调用实际执行了谁的代码**。

## 讲解

### 继承的最短用法

```text
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):
        return "汪"
```

`Dog` 继承了 `name` 和 `speak`；自己重写了 `speak`。`Dog("旺财").speak()` 走的是 `Dog` 那份。

### `super()` 是"父类那一份"

子类要保留父类的初始化再加自己的东西，就调 `super().__init__(...)`。不调的话父类那部分属性根本不存在，后面用到就报 `AttributeError`。

### 多态的用处

```text
for animal in [Dog("旺财"), Cat("咪咪")]:
    print(animal.speak())
```

这段代码**不知道**列表里有狗还是猫，也不需要知道。它只要求"每个对象都有 `speak`"。

这就是多态的全部价值：**调用方只依赖接口，不依赖具体类型**。加一个新动物，这段循环一个字都不用改。

### 抽象基类：让"必须实现"变成报错

```text
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        ...
```

子类忘了实现 `area`，一实例化就报错——比运行到一半才 `AttributeError` 好。

### 组合往往比继承好

判断标准很简单：**"是一个"用继承，"有一个"用组合**。

- `Dog` **是** `Animal` → 继承；
- `Car` **有** 一个 `Engine` → 组合（`self.engine = Engine()`）。

用继承去复用"一段代码"（而两者并非同一种东西）会让类型层级越来越怪，最后没人能说清某个类到底代表什么。

### 跑一遍

<!-- run -->
```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

    def __repr__(self):
        return f"{type(self).__name__}({self.name})"


class Dog(Animal):
    def speak(self):
        return "汪"


class Cat(Animal):
    def speak(self):
        return "喵"


animals = [Dog("旺财"), Cat("咪咪")]
for animal in animals:
    print(animal, animal.speak())

print(isinstance(Dog("旺财"), Animal))
print(all(hasattr(animal, "speak") for animal in animals))
```
```text
Dog(旺财) 汪
Cat(咪咪) 喵
True
True
```

`type(self).__name__` 在父类里，却打印出了子类的名字——**因为方法执行时的对象是子类实例**。

## 常见误区

### 误区：子类会自动调用父类的 `__init__`

**你以为**：继承之后父类的初始化会自己跑。
**其实**：不会。要在子类 `__init__` 里显式 `super().__init__(...)`。
**怎么验证**：写一个子类不调 super，然后访问父类设的属性，看是不是 `AttributeError`。

### 误区：继承是为了复用代码

**你以为**：只要两个类有共同代码就该继承。
**其实**：继承表达的是"是一种"。只为复用代码而继承，会让类型层级失真。复用优先用组合。

### 误区：`super()` 就是"调用父类"

**你以为**：不管什么情况都指向父类。
**其实**：它按方法解析顺序走"下一个"。多重继承时会跳到兄弟类，不是简单等于父类。

## 小结

子类重写方法后走子类那份。`super().__init__` 要把父类初始化补上。多态的价值是调用方不需要知道具体类型。"是一个"用继承，"有一个"用组合。
