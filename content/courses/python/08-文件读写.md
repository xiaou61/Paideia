# 08 · 文件读写

## 这一课你要会

- 用 `with open(...)` 读、写文本文件，并说明为什么必须用 `with`；
- 分清 `"r"`、`"w"`、`"a"` 三种模式，特别是 `"w"` 会清空文件；
- 知道路径相对谁、为什么中文要写 `encoding="utf-8"`。

## 为什么

前七课的变量都在内存里，程序一结束就没了。文件是让数据活过这一次运行的最小手段：读配置、存结果、记日志。

这一课最容易造成**不可挽回的损失**：`"w"` 模式打开一个已有文件，会立刻清空它——不是写入时清，是**打开时**就清。搞错一次，数据就没了。

## 讲解

### 必须用 `with`

```text
with open("data.txt", "r", encoding="utf-8") as file:
    content = file.read()
```

`with` 保证退出块时文件一定被关闭，哪怕中间抛了异常。不用 `with` 就要自己写 `finally: file.close()`——漏掉就会在 Windows 上遇到"文件被占用"。

### 三种模式

| 模式 | 行为 | 危险性 |
| --- | --- | --- |
| `"r"` | 读，文件不存在报错 | 安全 |
| `"w"` | 写，**文件存在则清空** | 高危 |
| `"a"` | 追加到末尾 | 安全 |
| `"x"` | 只在文件不存在时创建 | 安全 |

**要留旧内容就用 `"a"`**。要用 `"w"` 时先确认"这个文件里的东西我可以丢"。

### 逐行读

```text
with open("data.txt", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))
```

直接用 `for line in file` 比 `readlines()` 省内存：前者一次一行，后者一次全读进列表。

每行**保留行尾的换行符**，所以要 `rstrip("\n")`。不处理的话，下一课做字符串比较时会莫名其妙地不等。

### 路径相对谁

相对**当前工作目录**，不是脚本所在目录。所以"我明明把文件放在脚本旁边"却报"找不到文件"很常见。

### 跑一遍

这段会真写一个临时文件再读回来。注意 `"a"` 与 `"w"` 的区别。

<!-- run -->
```python
from pathlib import Path
import tempfile

folder = Path(tempfile.mkdtemp())
target = folder / "notes.txt"

with open(target, "w", encoding="utf-8") as file:
    file.write("第一行\n")

with open(target, "a", encoding="utf-8") as file:
    file.write("第二行\n")

with open(target, encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))

with open(target, "w", encoding="utf-8") as file:
    file.write("覆盖了\n")

with open(target, encoding="utf-8") as file:
    print(file.read().strip())

print(target.exists())
target.unlink()
print(target.exists())
```
```text
第一行
第二行
覆盖了
True
False
```

## 常见误区

### 误区：`"w"` 只是"准备写"，旧内容会保留到写入时

**你以为**：只是打开，还没写，数据还在。
**其实**：打开的那一刻就截断了。写失败也救不回来。
**怎么验证**：在测试目录建一个文件，用 `"w"` 打开后什么都不写就关闭，再看内容。

### 误区：文件路径是相对脚本所在的

**你以为**：`open("data.txt")` 会去脚本旁边找。
**其实**：相对的是**当前工作目录**。用 `Path(__file__).parent` 拼。

### 误区：不需要写 encoding

**你以为**：Python 会自己判断。
**其实**：默认编码随系统，Windows 上常不是 UTF-8。中文会乱码或直接报 `UnicodeDecodeError`。

## 小结

用 `with`，写 `encoding="utf-8"`。`"w"` 打开即清空，追加用 `"a"`。路径相对工作目录，用 `Path(__file__).parent` 拼。
