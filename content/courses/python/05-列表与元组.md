# 05 · 列表与元组

## 这一课你要会

- 建列表、按位置取、切片、增删改；
- 说清 `b = a` 和 `b = list(a)` 的差别，知道什么时候必须深拷贝；
- 知道元组为什么存在——它不只是"不能改的列表"。

## 为什么

真实的数据几乎都是"一串"。成绩是一串数字，文件名是一串字符串，订单是一串记录。列表就是 Python 里最常用的"一串"。

而列表最容易出事的地方不是语法，是**你以为你复制了，其实只是换个名字指着同一份数据**。这个 bug 会让两个本该独立的东西一起变。

## 讲解

### 下标从 0 开始，负数是倒着数

| 表达式 | 结果（`items = ["a", "b", "c", "d"]`） |
| --- | --- |
| `items[0]` | `"a"` |
| `items[-1]` | `"d"` |
| `items[1:3]` | `["b", "c"]` |
| `items[:2]` | `["a", "b"]` |
| `items[2:]` | `["c", "d"]` |

切片**左闭右开**，与 `range` 同一规则。切片总是返回新列表——这一点在"复制"里很关键。

### 常用操作

- `append(x)` 加到末尾、`insert(i, x)` 插到位置；
- `pop()` 取走末尾、`pop(i)` 取走指定位置；
- `remove(x)` 删掉第一个等于 x 的元素（找不到会报错）；
- `sort()` 原地排序、`sorted(x)` 返回新列表；
- `len()`、`sum()`、`max()`、`min()` 是内置函数，不是方法。

一个容易混的点：`items.sort()` 返回 `None`，不是排序后的列表。写 `x = items.sort()` 会让 `x` 变成 `None`。

### 赋值、浅拷贝、深拷贝

```text
a = [1, 2]
b = a           # 同一个列表，两个名字
c = a[:]        # 浅拷贝：新列表，元素还是原来那些对象
```

对扁平的列表（元素是数字、字符串），`a[:]` 或 `list(a)` 就够了。但元素本身是列表/字典时，浅拷贝只复制外层：

```text
outer = [[1], [2]]
shallow = outer[:]
shallow[0].append(9)
print(outer[0])   # [1, 9] —— 内层还是同一个
```

需要彻底独立时用 `copy.deepcopy(outer)`。**递归越深越要深拷贝**，而深拷贝也越慢——所以默认用浅拷贝，只在确认要改内层时才深拷。

### 元组：不可变，可哈希，能当字典的键

元组用圆括号，创建后不能改。它存在的理由不是"防止手滑"，而是：

- **可以当字典的键**（列表不行）；
- **可以放进集合**；
- 表达"这几个值是一组的、顺序有意义"：`(x, y)` 坐标、`(状态码, 内容)` 返回值。

只读的数据用元组，表达"我不打算改它"；要增删用列表。

### 跑一遍

<!-- run -->
```python
items = ["a", "b", "c", "d"]
print(items[0], items[-1])
print(items[1:3])

numbers = [3, 1, 2]
numbers.sort()
print(numbers)

wrong = numbers.sort()
print(wrong)

outer = [[1], [2]]
shallow = outer[:]
shallow[0].append(9)
print(outer)
print(shallow)

import copy
original = [[1], [2]]
deep = copy.deepcopy(original)
deep[0].append(9)
print(original)

point = (3, 4)
scores = {(1, 2): "起点", (5, 6): "终点"}
print(point[0], scores[(1, 2)])
```


注意 `sort()` 那两行：排序确实生效了，但返回值是 `None`。这是"原地修改的方法返回 None"的典型例子。

## 常见误区

### 误区：`b = a` 或 `list(a)` 就得到了完全独立的副本

**你以为**：复制之后两个列表互不影响。
**其实**：`b = a` 根本不是复制；`list(a)` 是浅拷贝，内层对象仍共享。
**怎么验证**：对二维列表做浅拷贝，改 `copy[0]`，看原列表是否跟着变。

### 误区：`items.sort()` 会返回排序后的列表

**你以为**：可以写 `result = items.sort()`。
**其实**：原地修改的方法都返回 `None`。要返回值用 `sorted(items)`。

### 误区：元组就是不能改的列表，没什么用

**你以为**：需要只读时直接用列表也行。
**其实**：元组可以当字典键、能进集合、能明确表达"这是一组固定字段"。`(状态码, 内容)` 这种返回比一个两元素列表清楚得多。

## 小结

下标从 0 开始、切片左闭右开。赋值不是复制，浅拷贝只复制外层。原地方法返回 `None`。只读的数据用元组。
