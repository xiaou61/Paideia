# 07 · 字符串与格式化

## 这一课你要会

- 用 f-string 把变量拼进句子，并控制小数位；
- 切分、去空白、替换、判断前缀后缀；
- 知道字符串不可变，所以"改一个字符"其实是造了一个新串。

## 为什么

程序的输入输出几乎都是文本：读到的文件、用户输入的命令、要写进日志的一行。文本处理是所有脚本的基础。

这一课的重点不是背方法名，而是知道**去哪找**：方法名记不住没关系，`dir(str)` 或查文档就行；但要知道"字符串不可变"这条，否则你会一直困惑于为什么某个方法不生效。

## 讲解

### f-string

```text
name = "小林"
score = 92.456
print(f"{name} 得了 {score:.1f} 分")
```

大括号里可以放表达式、可以带格式说明（`:.1f` 是一位小数、`:,` 是千分位、`>10` 是右对齐到 10 位）。

**优先用 f-string**：比 `+` 拼接清楚，比 `%` 格式化少一层括号，比 `format()` 少一个函数名。

### 常用方法

| 方法 | 作用 |
| --- | --- |
| `strip()` | 去掉两端空白（`lstrip` / `rstrip` 只去一边） |
| `split(sep)` | 按分隔符切成列表；不传参数按任意空白切 |
| `"sep".join(list)` | 用分隔符把列表接成字符串 |
| `replace(old, new)` | 替换全部 |
| `startswith` / `endswith` | 判断前缀后缀 |
| `lower` / `upper` | 转大小写 |
| `find` / `in` | 找位置 / 判断包含 |

**`split` 与 `join` 是互逆的**，注意 `join` 是分隔符在**前面**调用的：`"、".join(names)`。

### 不可变意味着什么

字符串一旦创建就不能改。`text.upper()` 不会改 `text`，它返回一个新的字符串。

```text
text = "abc"
text.upper()
print(text)          # 还是 abc
text = text.upper()  # 要接住返回值才会变
```

拼接大量字符串时这一点很费：`s = s + x` 在循环里每次都造一个新串。要拼很多段用列表收集再 `join`。

### 编码不是细节

文件读写默认按系统编码。Windows 默认可能不是 UTF-8，中文会变成乱码。**读写文件时显式写 `encoding="utf-8"`**，这一条下一课还会强调。

## 常见误区

### 误区：调用 `upper()` 之后原字符串就变了

**你以为**：`text.upper()` 是原地转换。
**其实**：字符串不可变，方法返回新串；不赋值就丢了。
**怎么验证**：调用后立刻打印原变量，再赋值回去打印一次。

### 误区：在循环里用 `+` 拼接大量字符串

**你以为**：这样最直观。
**其实**：每次都造一个新串，规模一大就很慢。用列表 `append` 再 `join`。

### 误区：`split()` 和 `split(" ")` 一样

**你以为**：都是按空格切。
**其实**：不带参数会按**任意连续空白**切并丢掉空串；带 `" "` 时连续两个空格会切出一个空字符串。

## 小结

用 f-string，不拼 `+`。字符串不可变，方法要接返回值。`split` 与 `join` 互逆。读写文件写死 UTF-8。
