# 10 · 类与对象

## 这一课你要会

- 定义带 `__init__` 的类，说清 `self` 是什么；
- 分清**类属性**与**实例属性**，知道为什么可变类属性会串数据；
- 给对象加方法，并决定"这个数据该存在对象里还是传进去"。

## 为什么

前九课的数据是"散着"的：一个人的名字在 `name`、成绩在 `scores` 字典里，操作它们的函数在别处。数据一多，就没人记得哪个函数该配哪份数据。

类是把这个绑定起来的手段：**对象同时带着数据和行为**。这也是读别人的代码时最常遇到的结构。

## 讲解

### 最小可用的类

```text
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_passing(self):
        return self.score >= 60
```

三件事：

1. **`__init__` 是构造时自动调的**，不是"构造函数"那种要手动 new 的东西；
2. **`self` 是那个对象自己**。`student.is_passing()` 调用时，Python 自动把 `student` 传进 `self`；
3. **属性在 `__init__` 里赋值**，这样每个对象都有自己的一份。

### 类属性与实例属性

```text
class Counter:
    total = 0            # 类属性：所有实例共享

    def __init__(self):
        self.count = 0   # 实例属性：每个对象一份
```

类属性适合**常量**（如 `MAX_SIZE = 100`）。如果类属性是可变对象（列表、字典），所有实例会共用同一个——这与上一课"可变默认参数"是完全同一类坑。

### 方法里的三种东西

- 只读 `self.x`：看自己的数据；
- 改 `self.x = ...`：改自己的数据，其它对象不受影响；
- 定义时不带 `self`：那是普通函数，得在类外面调。

`self` 不是关键字，只是约定；写成 `this` 也能跑，但没人这么写。

### `__repr__` 值得写

打印对象时默认得到 `<Student object at 0x...>`，没法用。写一个 `__repr__` 返回一句能看懂的字符串，排错时省很多时间。

### 什么时候该用类

- 数据和操作**总是成对出现**；
- 需要创建**很多个**同样结构的东西；
- 有状态要在多次调用之间保存。

只做一件事、不需要状态的逻辑，用函数就够了。**不要为了"面向对象"而给每个函数套个类**。

### 跑一遍

<!-- run -->
```python
class Student:
    school = "Paideia"

    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_passing(self):
        return self.score >= 60

    def __repr__(self):
        return f"Student(name={self.name!r}, score={self.score})"

a = Student("小林", 92)
b = Student("小周", 55)

print(a)
print(a.is_passing(), b.is_passing())
print(a.school, b.school)

a.score = 50
print(a.is_passing())

print(type(a).__name__)
print(isinstance(a, Student))
```


改 `a.score` 只影响 `a`：分数是实例属性。

## 常见误区

### 误区：`__init__` 是"构造函数"，必须手动调用

**你以为**：得先 `Student.__init__(...)`。
**其实**：`Student("小林", 92)` 会自动调用它并返回对象。

### 误区：类属性就是"默认值"，每个实例会自己复制一份

**你以为**：`scores = []` 写在类里，每个对象一份。
**其实**：只有不可变的类属性才像"默认值"；可变类属性是**共享的**。
**怎么验证**：建两个实例，往其中一个的 `self.scores` 追加，打印另一个的。

### 误区：给每个函数都套一个类才叫面向对象

**你以为**：类越多越专业。
**其实**：类是为了"数据和行为绑定"。没有状态、只算一次的，用函数更清楚。

## 小结

`__init__` 自动调用，`self` 是那个对象自己。可变数据放实例属性，别放类属性。只算结果不要状态时用函数。
