# Python 从零开始

这门课写给**完全没写过代码**的人。不假设你会命令行、不假设你懂英文报错、也不假设你知道什么是"环境"。

## 这门课怎么排

一共**十八课**，分三段推进：

- **会跑、会表达（1–4）**：环境、运算与条件、循环、函数；
- **数据怎么放（5–9）**：列表与元组、字典与集合、字符串、文件、异常；
- **程序怎么长大（10–18）**：类与对象、继承与多态，然后是真实项目里绕不开的六件事——模块与包、类型注解、生成器、装饰器、上下文管理器、并发。

前十二课保证你写得出能用的脚本；后六课保证你读得懂别人写的库。这个顺序与 Python 官方教程、哈佛 CS50P、赫尔辛基大学 MOOC.fi 的骨架一致，后段是按"日常代码里出现频率"补的。**不要跳过第 1 课直接看后面**——后面所有例子都假设你能把文件跑起来。

## 每课怎么用

- `讲解` 里有一个**能直接运行**的完整例子，先跑一遍再改几个值看变化；
- `动手` 是一个小练习，做完再看下面的解析；
- `检查一下` 是三道题，答对两题以上再往下走；
- `常见误区` 是别人踩过的坑，**先猜自己会不会踩**再读答案。

卡住的时候点右下角的助手，它会先问你想到哪一步了，而不是直接给答案。

## 学完能做什么

写得出"读一个文件、处理里面的数据、把结果写到另一个文件"这样的脚本，也读得懂别人的小项目：看到 `@decorator`、`with`、`yield`、`async` 不再发懵，知道它们各自解决什么问题。**离找工作还远**，但那不是这门课的目标；目标是让你不再怕代码。
