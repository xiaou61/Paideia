# 09 · 异常

## 这一课你要会

- 用 `try / except` 接住**具体**的异常，而不是一把抓；
- 用 `raise` 主动报错，用 `finally` 做收尾；
- 分清"能处理的"和"该让它崩的"，不写空的 `except`。

## 为什么

上一课的文件操作里有一堆"可能失败"：文件不存在、编码不对、没有权限。程序不可能预判所有情况。

异常机制的作用不是"让程序永不崩溃"，而是**在能处理的地方处理，在不能处理的地方让错误带着现场信息往上走**。

新手最常犯的错是写 `except:` 把一切都吞掉——结果程序看起来正常，数据却错了一半，而且没有任何线索。

## 讲解

### 基本形状

```text
try:
    可能出错的代码
except 具体异常 as error:
    处理
else:
    没出错时执行
finally:
    无论如何都执行
```

四个块都是可选的，但 `try` 必须配 `except` 或 `finally`。

### 只捕获你认识的异常

```text
try:
    value = int(text)
except ValueError:
    value = 0
```

`ValueError` 是"类型对但内容不对"（`int("abc")`）。文件不存在是 `FileNotFoundError`，取字典不存在的键是 `KeyError`，除零是 `ZeroDivisionError`。

**不要写 `except Exception:` 兜住一切**，更不要写裸 `except:`。前者会连你自己的代码 bug 一起吞掉，后者连 `KeyboardInterrupt` 都不放过——你连 Ctrl+C 都停不下程序。

### `raise` 与重新抛出

```text
def parse_age(text):
    if not text.isdigit():
        raise ValueError(f"年龄必须是数字，收到的是 {text!r}")
    return int(text)
```

主动报错时**把收到的值写进消息**——这是排错时唯一能救你的信息。

接了异常做点清理再往上抛，用 `raise`（不带参数）保留原始堆栈；`raise 新异常 from 原异常` 可以标明因果链。

### 自定义异常

```text
class OrderNotFound(Exception):
    pass
```

只要继承 `Exception` 就能被 `except` 接住。项目里需要区分"业务上的失败"和"程序错误"时用得上。

### 异常不是流程控制

用异常做正常的判断（比如"列表空了就抛异常然后接住"）会让代码难读、也慢。能用 `if` 判断的，先用 `if`。

### 跑一遍

<!-- run -->
```python
def parse_age(text):
    if not text.lstrip("-").isdigit():
        raise ValueError(f"年龄必须是数字，收到的是 {text!r}")
    return int(text)

for raw in ["18", "abc", "-3"]:
    try:
        print("解析成功：", parse_age(raw))
    except ValueError as error:
        print("解析失败：", error)

try:
    print(1 / 0)
except ZeroDivisionError:
    print("不能除以 0")
finally:
    print("收尾总是执行")
```
```text
解析成功： 18
解析失败： 年龄必须是数字，收到的是 'abc'
解析成功： -3
不能除以 0
收尾总是执行
```

## 常见误区

### 误区：`except:` 能让程序更稳

**你以为**：出错就跳过，程序继续跑。
**其实**：它把错误藏起来，数据可能已经错了一半。而且你连调试信息都拿不到。
**怎么验证**：在一个会崩的地方加 `except: pass`，看程序是不是"看起来正常但结果不对"。

### 误区：异常消息随便写就行

**你以为**：反正用户看不到。
**其实**：消息是唯一的现场证据。至少写清"收到了什么"和"期望什么"。

### 误区：异常该用来做正常分支

**你以为**：找不到就用异常表示"没有"。
**其实**：找不到返回 `None` 更清楚。异常留给"不该发生、发生了就是问题"的情况。

## 小结

只捕获认识的异常，别写裸 `except`。`finally` 做收尾。主动报错时把收到的值写进消息。能 `if` 判断的不用异常。
