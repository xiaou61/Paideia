# 04 · 函数

## 这一课你要会

- 定义带参数、带返回值的函数，并知道什么时候该抽成函数；
- 说清"可变默认参数只算一次"这个坑；
- 知道作用域是怎么回事，以及为什么循环里创建的 lambda 全都一样。

## 为什么

函数不只是"少写几遍"。它是**给一段逻辑起名字**：以后读代码的人看到 `is_valid_email(text)` 就知道这一步在干什么，不必读里面的正则。

这也是唯一能让程序长到几百行还不乱的机制。不会拆函数，代码到一百行就会开始互相纠缠。

## 讲解

### 定义与调用

```text
def 函数名(参数):
    """可选的一句话说明"""
    函数体
    return 结果
```

三个要点：

1. **没有 `return` 时返回 `None`**。忘了写 `return` 是新手的常见 bug，表现为"拿到 None 却不知道哪来的"。
2. **参数是值传递的名字绑定**。函数里给参数重新赋值，不会影响调用方外面的变量；但修改参数指向的**可变对象**（列表、字典）会。
3. **函数名用小写加下划线**，这是 Python 的通行约定。

### 默认参数只求值一次

这是本课最重要的一条：

```text
def add_item(item, items=[]):
    items.append(item)
    return items
```

`[]` 在**函数定义时**求值一次，之后所有调用共用同一个列表。所以第二次调用会看到上一次的内容。

正确写法是默认值用 `None`，进函数再创建：

```text
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

这条规则的适用范围比你想的广：任何可变对象（列表、字典、集合）都不能直接当默认值。

### 作用域

函数内部赋值的名字默认是**局部**的，函数外面看不到。要在函数里改外面的变量得用 `global`——但**几乎不需要**，需要了通常说明该用返回值或类。

读取外面定义的变量是允许的（闭包）。这也带来一个坑：

```text
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2]
```

lambda 里没有保存"当时的 i"，而是**调用时**去读外层的 `i`，那时循环已经结束，`i` 停在 2。想固定住当时的值得用默认参数 `lambda i=i: i`。

### 什么时候该抽函数

- 同一段逻辑在第二个地方出现；
- 一段代码需要一句注释才能说清（把它变成函数名）；
- 一段代码有自己的输入输出，可以单独测。

不必为了"每段都短"而拆成十几个两行的函数——那只是把复杂度挪到了调用链上。

### 跑一遍

<!-- run -->
```python
def greet(name, punctuation="!"):
    return "你好，" + name + punctuation

print(greet("小林"))
print(greet("小周", "。"))

def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item("a"))
print(add_item("b"))

funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])

def average(numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

print(average([80, 90, 100]))
print(average([]))
```
```text
你好，小林!
你好，小周。
['a']
['b']
[2, 2, 2]
90.0
0
```

注意 `average([])` 返回 `0` 而不是报错——**空输入要不要特判，是设计决定**，不是语法问题。这里选"返回 0"，因为调用方只关心一个数字。

## 常见误区

### 误区：默认参数每次调用都会新建

**你以为**：`def f(items=[])` 每次进来都是空列表。
**其实**：`[]` 在定义时创建一次，所有调用共用。这是 Python 里最经典的一类静默 bug。
**怎么验证**：连续调用两次带默认参数的 append 函数，打印第二次的结果。

### 误区：循环里的 lambda 会记住当时的变量值

**你以为**：`[lambda: i for i in range(3)]` 会得到 0、1、2。
**其实**：闭包在**调用时**读变量，三个函数读到的是同一个已经结束循环的 `i`。
**怎么验证**：把结果打印出来看是不是三个 2——是的话就说明你在调用时才读。

### 误区：函数越长越完整越好

**你以为**：一个函数把所有事做完，省得来回跳。
**其实**：函数长到看不清"输入是什么、输出是什么"时，就没法单独测，也没法复用。宁可多拆一个。

## 小结

函数是给逻辑起名字。没有 `return` 就是 `None`。可变对象不能当默认值。闭包读到的是调用时的变量。
