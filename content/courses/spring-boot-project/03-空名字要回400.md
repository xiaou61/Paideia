## 这一关要做什么

上一关的接口已经会返回 JSON 了。现在补上**出错时怎么回**——这是接口能不能给前端用的分界线：

```text
GET /api/greeting?name=%20%20        （名字是两个空格）
→ 400
{"error":"name 不能为空"}
```

```text
GET /api/greeting?name=Zoe
→ 200
{"message":"hello zoe","letters":9}
```

starter 里已经会**抛** `IllegalArgumentException` 了，但没告诉 Spring "这个异常该回 400"。
不告诉它的话，Spring 的默认行为是 **500**——前端拿到的是"服务器坏了"，而实际是**调用方传错了参数**。

只改 `src/main/java/demo/GreetingApi.java` 一个文件。

## 提示

- 处理方法的返回值用 `ResponseEntity<Map<String, String>>`，`ResponseEntity.badRequest().body(...)` 一步到位；
- 异常处理器写在**同一个控制器里**就行（`@ExceptionHandler(IllegalArgumentException.class)`），这一关不需要全局异常类；
- 别为了校验引 `spring-boot-starter-validation`：容器**没有网络**，加依赖装不上——这一关练的是"自己把错误翻译成状态码"。

```java
package demo;

import java.util.Map;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class GreetingApi {

    private final Greeter greeter = new Greeter();

    public record Greeting(String message, int letters) {
    }

    @GetMapping("/api/greeting")
    public Greeting greeting(@RequestParam String name) {
        String trimmed = name.trim().toLowerCase();
        if (trimmed.isEmpty()) {
            throw new IllegalArgumentException("name 不能为空");
        }
        String message = greeter.greet(trimmed);
        return new Greeting(message, message.length());
    }

    /** 参数错是调用方的问题，回 400 而不是 500。 */
    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<Map<String, String>> badRequest(IllegalArgumentException exception) {
        return ResponseEntity.badRequest().body(Map.of("error", exception.getMessage()));
    }
}
```
