# 从零做一个小 Spring Boot 项目

这条线和「手写迷你 Spring」的区别只有一句话：**那边是单文件里手写机制，这边是在真的项目结构里改代码**——
有 `pom.xml`、有包名、有多个源文件，判分是**真的跑一次 `mvn test`**。

## 怎么交

- 每关的骨架（`pom.xml`、`Application`、`HelloController`）已经在运行环境里，你只需要改**这一关标出来的那个文件**；
- 点「运行」会在一个隔离容器里编译整个项目并跑测试，**一次 15–30 秒**（Java 编译 + 起 Spring 上下文就是这个量级）；
- 判分只看测试是否全绿；失败时会点名是哪一条。

## 已知限制

- 容器**没有网络**：依赖全部预装在镜像里，所以不能临时加新的 starter。想加依赖的话，得在项目里真的做一次（这条线是让你练"改代码"，不是练"配环境"）；
- 每次运行都是全新容器，改一个字符也要全量编译——所以别反复点，一次改完再跑。

## 先修理论

建议先过「Spring 从零开始」的前 5 课（Maven 与第一个接口、分层、参数、返回值、手写 IoC），
再来这里把同样的东西落到一个真项目上。
