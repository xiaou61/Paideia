# Spring 从零开始

这门课接在 **Java 从零开始**（38 关）后面。那门课的最后一句话是"离写 Spring 服务还差一层"，这门课就是那一层。

它和多数 Spring 教程最大的不同：**不带你背注解，而是让你先把机制手写一遍**。讲容器就写一个 40 行的容器，讲 AOP 就用 `java.lang.reflect.Proxy` 自己织一个，讲事务就自己写"出错就还原"。手写完之后再回头看 `@Autowired`、`@Transactional`，你会发现它们没有魔法——它们只是在你手写的那套东西上加了个标记。

## 为什么是"先手写"

Spring 的绝大多数"诡异行为"都能用一句话解释：**你以为在调自己的对象，其实在调代理；或者反过来。**

这句话在你亲手写过一次动态代理之前只是句正确的废话。写过之后，`@Transactional` 加在 private 方法上失效、同类内部调用失效、异常被 `catch` 掉不回滚——这三件事会变成同一个原因，你不需要记。

所以每课的「讲解」里都有两段代码：

- **一段能真跑**（`<!-- run -->`，本页会真的编译执行并校验输出）——它用纯 Java 把机制写出来；
- **一段对照**（普通代码块）——它是真实项目里你会写的 Spring 代码。

## 二十课怎么排

分六个章节，按"能跑 → 会分层 → 懂容器 → 懂横切 → 会接数据 → 能交付"推进：

- **一 起步（1–4）**：Maven 与目录结构、第一个 `curl 200`、分层、参数从哪来、返回值与状态码。这一章结束时你能写出一个能被浏览器访问到的接口。
- **二 容器（5–9）**：手写 IoC 容器、`BeanDefinition` 与 `BeanFactory`、依赖注入与循环依赖、作用域与生命周期、自动配置与自定义 starter。这一章讲清"对象是谁 new 的"。
- **三 横切（10–13）**：手写动态代理、Spring AOP、事务就是切面、全局异常与参数校验。这一章讲清"为什么加了注解却不生效"。
- **四 Web（14–16）**：JSON 序列化、一次请求的完整旅程（过滤器 / 拦截器 / DispatcherServlet）、配置从哪来（优先级与 Profile）。
- **五 数据（17–18）**：JdbcTemplate 与连接池、手写 MyBatis 的映射。**本项目自己就是手写 MyBatis，不引 MyBatis-Plus**，这一章与真实代码同构。
- **六 交付（19–20）**：切片测试怎么写、打包成 jar、六条最常见的启动失败报错。

## 学完能做什么

能自己从空目录起一个 Spring Boot 服务，写分层、接数据库、写切片测试、打成 jar 部署；能在"注入了 null""事务没回滚""启动就退出"这三类问题面前，先判断是哪一层出了事，而不是挨个注解试。

**仍然不能**：写微服务、写响应式、写安全框架的深度定制。这三样各有自己的前提，本课不涉及。

## 一个前提

沙箱里的 JDK 是 **21**。本课所有示例都用 Java 17 以内的语法，在你自己的 JDK 17/21/25 上都能编译。Spring Boot 版本以 3.2+ 为准；如果你用的是 Boot 4，注意 `spring-boot-starter-web` 已改名为 `spring-boot-starter-webmvc`（本课会在第一次出现处标注）。

## 常见误区

### 误区：先把注解背下来，遇到问题再查

**你以为**：Spring 的能力来自注解，记得越多越会用。
**其实**：注解只是**标记**。真正干活的是启动时读标记、注册对象、生成代理的那套机制。同样一个 `@Transactional`，换个位置就完全失效，正说明起作用的是机制不是注解。
**怎么验证**：读完第 12 课，把 `@Transactional` 从一个 public 方法挪到同类里的另一个方法上，观察事务还开不开。

### 误区：Spring Boot 就是"Spring 加了一堆默认配置"

**你以为**：自动配置是一份写死的模板，只能照着它来。
**其实**：自动配置是一堆**带条件的配置类**，每个都写着"类路径上有 X、且用户没定义 Y 时我才生效"。你定义同名对象，它就自动让位。第 9 课会用一个 30 行的内核把这句演示一遍。

### 误区：能跑起来就说明我懂了

**你以为**：接口返回 200，这一课就过了。
**其实**：能跑起来只说明你抄对了。真正的分水岭是"它不跑的时候你知道先看哪儿"。第 20 课列了六条最常见的启动失败报错原文，那是这门课最实用的一页。
