# 14 · 文件 I/O

## 这一课你要会

- 用 `Files` 读写文本文件，并显式声明 UTF-8；
- 分清"覆盖写"与"追加写"，知道哪一次操作会清空旧文件；
- 知道路径相对谁，用 `Path` 而不是手工拼字符串。

## 为什么

程序的数据要活过这一次运行，就得落盘。而文件操作是**最容易造成不可挽回损失**的一类代码：`TRUNCATE_EXISTING` 一按，文件就没了。

Java 的 I/O API 有三代：`File`、`Files`、`NIO 通道`。这一课只讲 `Files`（Java 7 起，最简洁），其余遇到再查。

## 讲解

### 读一个文本文件

```text
import java.nio.file.Files;
import java.nio.file.Path;

String content = Files.readString(Path.of("data.txt"), StandardCharsets.UTF_8);
```

`readString` 一次读完全部内容。大文件用 `Files.lines(path)` 逐行流式处理：

```text
try (var lines = Files.lines(Path.of("data.txt"), StandardCharsets.UTF_8)) {
    lines.forEach(System.out::println);
}
```

`Files.lines` 返回的流**必须关闭**，所以要 try-with-resources。

### 写文件

```text
// 覆盖：文件存在则清空
Files.writeString(path, "内容", StandardCharsets.UTF_8);

// 追加
Files.writeString(path, "更多", StandardCharsets.UTF_8,
        StandardOpenOption.CREATE, StandardOpenOption.APPEND);
```

**默认是覆盖**。这一点与 Python 的 `"w"` 相同：不传 `APPEND` 就是把旧内容丢掉。**打开的那一刻就截断**，不是写到第一个字符才截断。

### 编码必须显式写

不写编码时用平台默认。Windows 上常常不是 UTF-8，中文会乱码或抛 `MalformedInputException`。

**规则：所有文本 I/O 都写 `StandardCharsets.UTF_8`。** 这不是讲究，是可移植性。

### 路径

```text
Path base = Path.of("data");
Path file = base.resolve("notes.txt");
```

`Path.of(...)` 把字符串变成路径对象，`resolve` 拼子路径。**不要用字符串 `+ "/"` 拼**：Windows 分隔符不同，而且路径里的 `..` 需要规范化。

`Path.of("data.txt")` 是**相对当前工作目录**的，不是相对类文件或项目根。要看当前目录用 `Path.of(".").toAbsolutePath()`。

### 检查与创建

```text
Files.exists(path)
Files.createDirectories(path.getParent())   // 不存在就建，包括上层
Files.size(path)
Files.delete(path)                          // 不存在会抛异常
Files.deleteIfExists(path)                  // 幂等
```

### 跑一遍

<!-- run -->
```java
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.util.List;

public class Main {
    public static void main(String[] args) throws Exception {
        Path folder = Files.createTempDirectory("paideia-io-");
        Path file = folder.resolve("notes.txt");

        Files.writeString(file, "第一行\n", StandardCharsets.UTF_8);
        Files.writeString(file, "第二行\n", StandardCharsets.UTF_8,
                StandardOpenOption.CREATE, StandardOpenOption.APPEND);

        System.out.println(Files.readString(file, StandardCharsets.UTF_8).strip());

        List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
        System.out.println(lines.size());
        System.out.println(lines.get(0));

        Files.writeString(file, "覆盖了\n", StandardCharsets.UTF_8);
        System.out.println(Files.readString(file, StandardCharsets.UTF_8).strip());

        System.out.println(Files.exists(file));
        Files.deleteIfExists(file);
        System.out.println(Files.exists(file));

        Files.deleteIfExists(folder);
    }
}
```

```text
第二行
2
第一行
覆盖了
true
false
```

## 常见误区

### 误区：`writeString` 只是"准备写"

**你以为**：文件内容还在，直到写入第一个字符。
**其实**：默认覆盖，打开即截断。写失败也救不回旧内容。
**怎么验证**：对已有文件调用一次不传选项的 `writeString`，再读回来看。

### 误区：编码可以让程序自己判断

**你以为**：Java 会猜。
**其实**：不写就用平台默认。跨平台就出问题。

### 误区：路径可以用字符串拼

**你以为**：`folder + "/" + name` 就行。
**其实**：分隔符在 Windows 上不同，且无法规范化 `..`。用 `Path.resolve`。

## 小结

`Files.readString` / `writeString`，**一律写 UTF-8**。默认覆盖，追加要 `APPEND`。路径用 `Path.resolve`。流式读用 `Files.lines` 并确保关闭。
