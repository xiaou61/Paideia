# 03 · 循环与方法

## 这一课你要会

- 用 `for`、`while`、`for-each` 三种循环，知道各自适合什么；
- 写带参数、带返回值的方法，理解"重载"是什么；
- 说清为什么"循环里拼字符串"在 Java 里格外费。

## 为什么

循环与方法是最基本的控制手段。Java 的循环比 Python 多一点：`for (int i = 0; ...)` 这种三段式是它的传统形状，读别人的代码绕不过去。

方法在本课出现，也正好说明"Java 里的方法必须写在类里"——这一点与 Python 的顶层函数不同。

## 讲解

### 三种循环

```text
for (int i = 0; i < 3; i++) { ... }   // 次数确定
for (String name : names) { ... }      // 遍历集合/数组
while (condition) { ... }              // 条件驱动
do { ... } while (condition);          // 至少执行一次
```

`for` 的三段是"初始化; 条件; 每轮之后做什么"。`i < 3` 用的是 `<` 不是 `<=`，这是 Java 里下标从 0 开始的通行写法。

### 方法：返回类型必须写

```text
static int add(int a, int b) {
    return a + b;
}
```

- **返回类型**写在方法名前面。没有返回值写 `void`；
- **所有路径都要 return**，否则编译报 `missing return statement`；
- 方法必须先声明再使用（同一个类里顺序不重要）。

### 重载

同名方法、不同参数列表，就是重载：

```text
static int add(int a, int b)
static double add(double a, double b)
```

调用时按参数类型选。**参数个数或类型必须不同**；只改返回类型不算重载，编译报错。

### 字符串拼接的代价

`String` 不可变，`s = s + x` 在循环里每次都造一个新串，规模一大就慢。用 `StringBuilder`：

```text
StringBuilder builder = new StringBuilder();
builder.append("a").append("b");
String result = builder.toString();
```

编译器会在简单拼接时自动优化成 `StringBuilder`，但**循环里的拼接它优化不了**（每次循环是一次独立的拼接）——所以循环里要手动用。

### 局部变量作用域

在 `for` 的括号里声明的 `i` 只在循环内可见。出了循环再用就编译失败——这是好事，防止拿一个"已经过期"的计数。

### 跑一遍

<!-- run -->
```java
public class Main {
    static int sumTo(int limit) {
        int total = 0;
        for (int i = 1; i <= limit; i++) {
            total += i;
        }
        return total;
    }

    static String join(String[] parts, String separator) {
        StringBuilder builder = new StringBuilder();
        for (int i = 0; i < parts.length; i++) {
            if (i > 0) {
                builder.append(separator);
            }
            builder.append(parts[i]);
        }
        return builder.toString();
    }

    public static void main(String[] args) {
        System.out.println(sumTo(4));

        String[] names = {"小林", "小周", "小陈"};
        for (String name : names) {
            System.out.println(name);
        }

        System.out.println(join(names, "、"));

        int countdown = 3;
        while (countdown > 0) {
            System.out.println(countdown);
            countdown--;
        }

        int attempts = 0;
        do {
            attempts++;
        } while (attempts < 2);
        System.out.println("尝试次数：" + attempts);
    }
}
```


## 常见误区

### 误区：方法可以不写返回类型

**你以为**：像 Python 那样直接写 `def`。
**其实**：Java 必须写返回类型，没返回值写 `void`。

### 误区：`s = s + x` 在 Java 里和 StringBuilder 差不多

**你以为**：编译器都会优化。
**其实**：简单的一句会优化，循环里每次迭代都是独立的拆分优化，优化不了。

### 误区：`while` 循环里的变量在外面也能用

**你以为**：整个方法内共享。
**其实**：作用域最小到声明它的块。出了块就不可见。

## 小结

循环三种，`for-each` 遍历最清楚。方法必须声明返回类型，所有路径要 return。重载看参数列表。循环拼字符串用 `StringBuilder`。
