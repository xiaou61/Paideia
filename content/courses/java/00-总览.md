# Java 从零开始

这门课写给**完全没写过代码**的人。不假设你会命令行、不假设你懂英文报错、也不假设你知道什么是"编译"。

## 为什么 Java 比 Python 多一道坎

Python 写完直接跑。Java 要先把源码**编译**成字节码，再由 JVM 执行。这道坎不是麻烦，它带来两件事：

- **编译期就能发现一批错误**（类型不对、方法名拼错），不必等到运行；
- **同一份字节码能在任何装了 JVM 的机器上跑**。

代价是起步多两个命令：`javac` 和 `java`。这一课会用最少的步骤把它们讲清楚。

## 三十五课怎么排

一共**三十五课**，分十二个章节，按"能跑 → 会表达 → 会组织 → 会用标准库 → 懂运行时 → 读懂现代代码"推进。前 23 课的顺序不变；后两章是补的 12 课，专补"看得懂别人代码、查得动线上问题"需要的东西：

- **起步（1）**：编译运行、八种基本类型；
- **流程控制（2–3）**：条件、`switch`、循环、方法；
- **数组与字符串（4）**：定长数组、不可变字符串、数组协变；
- **类与对象（5–6）**：构造器、封装、`static`、值传递；
- **继承与接口（7）**：抽象类、接口、重写与替换；
- **集合与字符串（8–10）**：`List`/`Map`/`Set`、字符串池、装箱缓存；
- **equals 与集合选型（11–12）**：为什么必须成对重写、四种集合怎么挑；
- **工程实践（13–16）**：异常、文件 I/O、测试与构建、小项目；
- **泛型与函数式（17–21）**：泛型、`Optional`、日期时间、Stream、Lambda；
- **并发与运行时（22–23）**：线程池、可见性、JVM 内存与 GC；
- **工程补遗（24–28）**：枚举、注解与反射、正则、字符编码、日志；
- **现代 Java（29–35）**：`var`、文本块、`switch` 表达式、模式匹配、`record`、`sealed`、虚拟线程。

**Java 的门槛比 Python 高**：要到第 5 课（类与对象）之后，你才真正开始能写"像个程序"的东西。这很正常，别在第 3 课就怀疑自己。

后 12 课不是"高级话题收藏夹"，它们各自对应一类你很快就会遇到的东西：

| 遇到什么 | 该看哪几课 |
| --- | --- |
| 框架里的 `@Service`、`@Transactional` 到底是什么 | 25（注解与反射） |
| 日志里一堆时间戳和线程名，不知道看哪行 | 28（日志） |
| 中文乱码、文件读出来是问号 | 27（字符编码） |
| 校验手机号、拆分路径、匹配日志格式 | 26（正则） |
| 同事代码里的 `var`、`record`、`switch ->`、`instanceof X x` | 29–34（现代 Java） |
| 一万个请求就要开一万个线程，扛不住 | 35（虚拟线程） |

## 每课怎么用

- `讲解` 里有一个**能编译能运行**的完整例子，先跑一遍再改几个值；
- `动手` 是一个小练习；
- `检查一下` 三道题，答对两题再往下；
- `常见误区` 是别人踩过的坑。

卡住时点右下角的助手。它会先问你想到哪一步，而不是直接贴答案。

## 这门课与实战线怎么配

「从零开始」的实战是另外两条轨道，**不锁**——想直接动手随时能进。但下面这张表说明它们默认你上过哪些课；没上过也能做，只是遇到报错时会更费劲：

| 实战线 | 默认先掌握 |
| --- | --- |
| **Java 调试实战**（8 道改错题） | 1–4（变量、条件、循环、数组）+ 9–11（字符串、装箱、equals/hashCode） |
| **Java 项目实战**（4 个小项目） | 1–16（到异常、I/O 与测试为止）；第 3、4 个项目还会用到 8、12、20 的集合与 Stream |

两条线都只要求**能读、能改一个文件**，不要求你会搭框架。

## 学完能做什么

读得懂一个几百行的 Java 类，能自己写命令行小工具，知道 `equals` 和 `==` 的区别、知道泛型擦除意味着什么、能看着 `jstack`/GC 日志说出程序卡在哪，也能读懂 `record`、`sealed`、模式匹配这些 17 以后的新写法。**离写 Spring 服务还差一层**：那层是「Spring」阅读线的内容，不是这门课没讲完。
