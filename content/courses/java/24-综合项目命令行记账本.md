# 24 · 综合项目：命令行记账本

## 这一课你要会

- 用 `record` 表达一条账目，并让金额、分类在构造时就受约束；
- 用 `List` 与 `Stream` 算出收入、支出、结余和分类合计；
- 用 `Files` + UTF-8 读写 CSV，知道为什么不能靠平台默认编码；
- 用 `BigDecimal` 存金额，说清 `double` 和 `new BigDecimal(0.1)` 的问题；
- 把输入错误与 I/O 错误分开处理，让一条脏输入不会结束程序；
- 按"数据 / 汇总 / 存储 / 入口"拆方法，并写一个不碰文件的自检。

## 为什么

前 23 课是单个知识点：类、集合、异常、文件、日期、Stream。真实的小工具不是这样长出来的——它要同时用上这些，而且每一处都不能省：

- 金额算错，工具就没有意义；
- 文件编码不对，换台机器就全是乱码；
- 一条脏输入让程序崩掉，用户就不敢再用；
- 所有逻辑挤在 `main` 里，改一个需求要通读全文。

记账本足够小，一天能写完；但它把上面四件事全都碰到了。这一课的重点不是"记账"，是**把已经会的东西摆成一个能交付的程序**。

## 讲解

### 先定数据模型

一条账目只需要四个字段：日期、分类、备注、金额。用 `record` 是因为它天生不可变，`equals`/`hashCode`/`toString` 都由编译器生成，正好适合"一条记录"。

金额用**有符号**的 `BigDecimal`：收入为正，支出为负。这样"结余"就是简单求和，不需要额外的类型字段。

```java
import java.math.BigDecimal;
import java.time.LocalDate;

public record Entry(LocalDate date, String category, String note, BigDecimal amount) {

    public Entry {
        if (date == null) {
            throw new IllegalArgumentException("日期不能为空");
        }
        if (category == null || category.isBlank()) {
            throw new IllegalArgumentException("分类不能为空");
        }
        if (note == null) {
            note = "";
        }
        if (amount == null || amount.signum() == 0) {
            throw new IllegalArgumentException("金额不能为 0");
        }
    }

    public boolean isIncome() {
        return amount.signum() > 0;
    }
}
```

`public Entry { ... }` 是**紧凑构造器**：校验写在里面，字段赋值由编译器补在最后。校验放在这里的好处是——**任何**创建账目的路径都绕不过它，包括以后从数据库或网络读进来的数据。

### 汇总是一个纯函数

`Summary` 只接收一组账目，返回结果，不读文件、不打印。所以它能被直接测。

```java
import java.math.BigDecimal;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;
import java.util.stream.Collectors;

public record Summary(BigDecimal income, BigDecimal expense, BigDecimal balance,
                      Map<String, BigDecimal> byCategory) {

    public static Summary of(List<Entry> entries) {
        BigDecimal income = entries.stream()
                .filter(Entry::isIncome)
                .map(Entry::amount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
        BigDecimal expense = entries.stream()
                .filter(entry -> !entry.isIncome())
                .map(entry -> entry.amount().abs())
                .reduce(BigDecimal.ZERO, BigDecimal::add);
        Map<String, BigDecimal> byCategory = entries.stream()
                .collect(Collectors.groupingBy(
                        Entry::category,
                        TreeMap::new,
                        Collectors.reducing(BigDecimal.ZERO, Entry::amount, BigDecimal::add)));
        return new Summary(income, expense, income.subtract(expense), byCategory);
    }
}
```

两个细节：

- 分类合计用 `TreeMap`，输出顺序固定，测试和肉眼对比都方便。它按字符编码排序，**不是拼音**，所以"交通"会排在"工资"前面。
- 空账本时 `reduce` 返回 `BigDecimal.ZERO`，不会抛异常。这一点要写进自检。

### 命令循环

命令行工具的主干是一个循环：打印提示、读一行、分派、再回来。用 `switch` 的箭头写法，不会意外贯穿到下一个分支。

```java
while (true) {
    System.out.print("> ");
    if (!scanner.hasNextLine()) {
        return;                       // Ctrl+D / Ctrl+Z：正常退出
    }
    String command = scanner.nextLine().trim();
    switch (command) {
        case "add" -> add();
        case "list" -> list();
        case "summary" -> summary();
        case "quit", "exit" -> {
            System.out.println("再见");
            return;
        }
        case "" -> { }                // 直接回车，忽略
        default -> System.out.println("未知命令：" + command);
    }
}
```

循环本身只做**分派**。读日期、读金额、算汇总、写文件都在各自的方法里——这样每个方法都短到一眼能看完。

### 金额只用 BigDecimal

`double` 在二进制里存不下 0.1，只能存一个非常接近的值。累加之后误差会露出来：

```java
System.out.println(0.1 + 0.2);                        // 0.30000000000000004
System.out.println(new BigDecimal("0.1").add(new BigDecimal("0.2")));  // 0.3
```

两条规则：

1. **金额、单价、税率一律 `BigDecimal`**，不要经过 `double`；
2. 从字符串构造：`new BigDecimal("28.50")`。`new BigDecimal(28.50)` 会把 `double` 已经损失的误差原样搬进来。

还有两个容易忽略的点：

- `BigDecimal.equals` **连小数位数一起比**，`new BigDecimal("1.0").equals(new BigDecimal("1.00"))` 是 `false`；判断数值相等用 `compareTo(...) == 0`。
- 除法可能除不尽，必须给精度和舍入方式：`a.divide(b, 2, RoundingMode.HALF_UP)`，否则可能抛 `ArithmeticException`。本项目的汇总只有加减，不涉及这条。

### CSV 与编码

存储格式选 CSV：一行一条，人能直接看，Excel 也能打开。

```text
date,category,note,amount
2026-10-01,工资,九月工资,8000.00
2026-10-02,餐饮,午饭,-28.50
```

读写都用 `Files`，并且**显式写 UTF-8**：

```java
List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
Files.write(temp, lines, StandardCharsets.UTF_8);
```

不写编码的 `FileReader` / `FileWriter` 用的是**默认字符集**。JDK 18 起它默认是 UTF-8，但老项目、显式设了 `-Dfile.encoding=GBK` 的程序，以及别的工具写出的文件仍可能是 GBK/ANSI。只要读写两端不一致，换台机器就可能乱码，或者读的时候直接抛 `MalformedInputException`。

保存时先写临时文件、再替换原文件：

```java
Path temp = file.resolveSibling(file.getFileName() + ".tmp");
Files.write(temp, lines, StandardCharsets.UTF_8);
Files.move(temp, file, StandardCopyOption.REPLACE_EXISTING);
```

这样写到一半失败，原账本还在。直接往原文件上写，失败时可能只剩半本账。

`shortcut: 字段里不允许逗号和换行，等要导入别人生成的 CSV 时换成带转义解析的库。`

### 异常处理：分边界

这个程序只有两个不可信边界：**用户输入**和**文件系统**。异常处理也按这两类分：

| 边界 | 可能抛什么 | 怎么处理 |
| --- | --- | --- |
| 用户输入 | `DateTimeParseException`、`NumberFormatException`、`IllegalArgumentException` | 打印"输入有误：..."，回到命令循环，**不退出** |
| 文件读写 | `IOException` | 打印"读写失败：..."，明确告诉用户这次没保存成功 |

三条纪律：

- **不吞异常**：`catch (Exception e) {}` 会让写盘失败看起来像成功；
- **不抓过宽**：只抓这两个边界上真会发生的类型，别把编程错误也一起藏掉；
- **不假装成功**：`save` 抛异常时，不能打印"已保存"。

### 拆方法的判据

用一句话判断拆得对不对：**"我想测这条规则，需要造文件吗？"**

需要，说明业务逻辑漏进了存储层。本项目的分法：

```text
Entry.java       数据：一条账目 + 构造校验
Summary.java     汇总：纯函数，输入 List<Entry>，输出 Summary
CsvStore.java    存储：唯一碰文件的地方
Main.java        入口：命令循环、读输入、调用前三层
SelfCheck.java   自检：不碰文件，只验汇总
```

以后要换成数据库，只改 `CsvStore`；要加"按月份统计"，只改 `Summary`；命令怎么变，只改 `Main`。

### 如何自测

测试的本质是**断言**，不是"我看了一眼输出是对的"。

`assert` 关键字默认是关闭的，要加 `-ea` 才生效；忘了加就静默通过——这比没有测试更危险。所以这里直接写显式检查，任何一次运行都会执行：

```java
static void check(boolean condition, String message) {
    if (!condition) {
        throw new AssertionError(message);
    }
}
```

自检至少覆盖四个点：

- 只有收入时，支出为 0；
- 只有支出时，收入为 0；
- 结余 = 收入 - 支出；
- 空账本不抛异常，结余为 0。

数值比较用 `compareTo(...) == 0`，不用 `equals`，避免小数位数不同造成的假失败。

### 先跑一遍核心

下面这段把数据模型和汇总压进一个文件，用内存里的四条账目直接打印结果。它不读文件、不读输入，所以输出每次完全一样。

<!-- run -->
```java
import java.math.BigDecimal;
import java.time.LocalDate;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;
import java.util.stream.Collectors;

public class Main {

    record Entry(LocalDate date, String category, String note, BigDecimal amount) {
        boolean isIncome() {
            return amount.signum() > 0;
        }
    }

    static BigDecimal sum(List<Entry> entries) {
        return entries.stream()
                .map(Entry::amount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
    }

    static BigDecimal income(List<Entry> entries) {
        return sum(entries.stream().filter(Entry::isIncome).toList());
    }

    static BigDecimal expense(List<Entry> entries) {
        return sum(entries.stream().filter(entry -> !entry.isIncome()).toList()).abs();
    }

    static Map<String, BigDecimal> byCategory(List<Entry> entries) {
        return entries.stream().collect(Collectors.groupingBy(
                Entry::category,
                TreeMap::new,
                Collectors.reducing(BigDecimal.ZERO, Entry::amount, BigDecimal::add)));
    }

    public static void main(String[] args) {
        List<Entry> ledger = List.of(
                new Entry(LocalDate.of(2026, 10, 1), "工资", "九月工资", new BigDecimal("8000.00")),
                new Entry(LocalDate.of(2026, 10, 2), "餐饮", "午饭", new BigDecimal("-28.50")),
                new Entry(LocalDate.of(2026, 10, 3), "交通", "地铁", new BigDecimal("-6.00")),
                new Entry(LocalDate.of(2026, 10, 4), "餐饮", "晚饭", new BigDecimal("-42.00")));

        System.out.println("收入：" + income(ledger));
        System.out.println("支出：" + expense(ledger));
        System.out.println("结余：" + sum(ledger));
        byCategory(ledger).forEach((category, amount) ->
                System.out.println(category + "：" + amount));
    }
}
```

```text
收入：8000.00
支出：76.50
结余：7923.50
交通：-6.00
工资：8000.00
餐饮：-70.50
```

注意分类顺序是 `交通 → 工资 → 餐饮`：`TreeMap` 按字符编码排，不是按拼音。要按金额大小排，得先排序再输出。

### 完整版本：四个文件

下面是可以直接编译运行的完整代码。先看存储层——它是唯一碰文件的地方。

```java
// CsvStore.java
import java.io.IOException;
import java.math.BigDecimal;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;

public final class CsvStore {

    private static final String HEADER = "date,category,note,amount";

    private final Path file;

    public CsvStore(Path file) {
        this.file = file;
    }

    public List<Entry> load() throws IOException {
        List<Entry> entries = new ArrayList<>();
        if (Files.notExists(file)) {
            return entries;                       // 第一次运行：空账本
        }
        List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
        for (int i = 0; i < lines.size(); i++) {
            String line = lines.get(i).trim();
            if (line.isEmpty() || line.equals(HEADER)) {
                continue;
            }
            entries.add(parse(line, i + 1));
        }
        return entries;
    }

    public void save(List<Entry> entries) throws IOException {
        List<String> lines = new ArrayList<>();
        lines.add(HEADER);
        for (Entry entry : entries) {
            lines.add(String.join(",", entry.date().toString(), entry.category(),
                    entry.note(), entry.amount().toPlainString()));
        }
        // 先写临时文件再替换：写到一半失败，原账本还在
        Path temp = file.resolveSibling(file.getFileName() + ".tmp");
        Files.write(temp, lines, StandardCharsets.UTF_8);
        Files.move(temp, file, StandardCopyOption.REPLACE_EXISTING);
    }

    private Entry parse(String line, int lineNumber) {
        String[] parts = line.split(",", -1);
        if (parts.length != 4) {
            throw new IllegalArgumentException("第 " + lineNumber + " 行列数不对：" + line);
        }
        try {
            return new Entry(LocalDate.parse(parts[0]), parts[1], parts[2],
                    new BigDecimal(parts[3]));
        } catch (RuntimeException error) {
            throw new IllegalArgumentException("第 " + lineNumber + " 行解析失败：" + line, error);
        }
    }
}
```

入口层只负责读输入和调用：

```java
// Main.java
import java.io.IOException;
import java.math.BigDecimal;
import java.nio.file.Path;
import java.time.LocalDate;
import java.time.format.DateTimeParseException;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {

    private final Path file;
    private final CsvStore store;
    private final List<Entry> entries;
    private final Scanner scanner;

    public Main(Path file, Scanner scanner) throws IOException {
        this.file = file;
        this.store = new CsvStore(file);
        this.entries = new ArrayList<>(store.load());
        this.scanner = scanner;
    }

    public static void main(String[] args) throws IOException {
        Path file = Path.of(args.length > 0 ? args[0] : "ledger.csv");
        try (Scanner scanner = new Scanner(System.in)) {
            new Main(file, scanner).run();
        }
    }

    public void run() {
        System.out.println("记账本：add / list / summary / quit");
        while (true) {
            System.out.print("> ");
            if (!scanner.hasNextLine()) {
                return;
            }
            String command = scanner.nextLine().trim();
            try {
                switch (command) {
                    case "add" -> add();
                    case "list" -> list();
                    case "summary" -> summary();
                    case "quit", "exit" -> {
                        System.out.println("已保存 " + entries.size() + " 条到 " + file);
                        return;
                    }
                    case "" -> { }
                    default -> System.out.println("未知命令：" + command);
                }
            } catch (DateTimeParseException | IllegalArgumentException error) {
                System.out.println("输入有误：" + error.getMessage());
            } catch (IOException error) {
                System.out.println("读写失败：" + error.getMessage());
            }
        }
    }

    private void add() throws IOException {
        System.out.print("日期（如 2026-10-26）：");
        LocalDate date = LocalDate.parse(nextLine());
        System.out.print("分类（如 餐饮）：");
        String category = nextLine();
        System.out.print("备注：");
        String note = nextLine();
        System.out.print("金额（收入为正，支出为负）：");
        BigDecimal amount = new BigDecimal(nextLine());
        entries.add(new Entry(date, category, note, amount));
        store.save(entries);
        System.out.println("已保存，当前 " + entries.size() + " 条");
    }

    private void list() {
        if (entries.isEmpty()) {
            System.out.println("还没有记录");
            return;
        }
        for (int i = 0; i < entries.size(); i++) {
            Entry entry = entries.get(i);
            System.out.printf("%3d  %s  %-6s  %10s  %s%n",
                    i + 1, entry.date(), entry.category(),
                    entry.amount().toPlainString(), entry.note());
        }
    }

    private void summary() {
        Summary summary = Summary.of(entries);
        System.out.println("收入：" + summary.income());
        System.out.println("支出：" + summary.expense());
        System.out.println("结余：" + summary.balance());
        summary.byCategory().forEach((category, amount) ->
                System.out.println("  " + category + "：" + amount));
    }

    private String nextLine() {
        if (!scanner.hasNextLine()) {
            throw new IllegalArgumentException("输入提前结束");
        }
        return scanner.nextLine().trim();
    }
}
```

最后是自检。它只依赖 `Entry` 和 `Summary`，不需要创建文件：

```java
// SelfCheck.java
import java.math.BigDecimal;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;

public class SelfCheck {

    static void check(boolean condition, String message) {
        if (!condition) {
            throw new AssertionError(message);
        }
    }

    public static void main(String[] args) {
        List<Entry> sample = List.of(
                new Entry(LocalDate.of(2026, 10, 1), "工资", "工资", new BigDecimal("8000.00")),
                new Entry(LocalDate.of(2026, 10, 2), "餐饮", "午饭", new BigDecimal("-28.50")),
                new Entry(LocalDate.of(2026, 10, 3), "交通", "地铁", new BigDecimal("-6.00")));

        Summary summary = Summary.of(sample);
        check(summary.income().compareTo(new BigDecimal("8000.00")) == 0, "收入算错");
        check(summary.expense().compareTo(new BigDecimal("34.50")) == 0, "支出算错");
        check(summary.balance().compareTo(new BigDecimal("7965.50")) == 0, "结余算错");
        check(Summary.of(new ArrayList<>()).balance().signum() == 0, "空账本结余应为 0");

        System.out.println("自测通过");
    }
}
```

### 这一课不讲的

CSV 转义（字段含逗号、引号、换行）、多进程同时写同一个文件、按月/按年报表、导入银行流水、加密存储——这些都需要额外的设计。先把"单进程、单人用、能正确保存"这一层做扎实。

## 常见误区

### 误区：金额用 double 就行

**你以为**：`double` 能存小数，记个账够用了。
**其实**：0.1 在二进制里是无限循环，`0.10 + 0.20` 得到 `0.30000000000000004`，累加越多偏差越大。金额必须从一开始就用 `BigDecimal`，不能"最后再转"。
**怎么验证**：打印 `0.1 + 0.2`，再打印 `new BigDecimal("0.1").add(new BigDecimal("0.2"))`，对比两个结果。

### 误区：`new BigDecimal(0.1)` 和 `new BigDecimal("0.1")` 一样

**你以为**：都是 0.1，随便用哪个构造器。
**其实**：`double` 构造器把已经损失的二进制值原样搬进来，打印出来是一长串；字符串构造器按十进制精确解析。
**怎么验证**：分别打印两个对象的 `toPlainString()`，看第一个有多少位。

### 误区：不指定编码也能读写中文

**你以为**：`Files.readString(path)` 或 `FileWriter` 默认就是 UTF-8。
**其实**：它们用平台默认编码。Windows 中文环境常是 GBK，Linux 和容器常是 UTF-8，同一份文件换台机器就可能乱码或抛 `MalformedInputException`。
**怎么验证**：在 Windows 上写一个含中文的 CSV，再拿到 Linux 容器里读；或者用 `-Dfile.encoding=GBK` 启动程序读同一份文件。

### 误区：catch 住异常就算处理了

**你以为**：`catch (Exception e) {}` 让程序不崩，就是健壮。
**其实**：吞掉写盘失败会让用户以为数据已经保存。正确做法是明确告诉用户哪一步失败，并且不要在失败时覆盖原文件。
**怎么验证**：把 CSV 路径指向一个只读目录，执行 `add`，看程序是否明确报告保存失败，以及原文件是否还在。

## 小结

- 数据用不可变 `record`，校验写在紧凑构造器里，所有入口都绕不过。
- 汇总写成纯函数：输入 `List<Entry>`，输出 `Summary`，不碰文件、不打印。
- 命令循环只做分派，读写输入、保存、汇总各自成方法。
- 金额只用 `BigDecimal`，从字符串构造，比较用 `compareTo`。
- CSV 显式用 UTF-8；保存先写临时文件再替换，失败不毁原账本。
- 输入错误让用户重试，I/O 错误必须报告，两类异常分开处理。
- 自测用显式断言，覆盖空账本、纯收入、纯支出与结余关系。
