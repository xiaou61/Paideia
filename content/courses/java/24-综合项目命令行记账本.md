# 24 · 综合项目：命令行记账本

## 三笔账，重启后变成六笔

先把存储层单独拿出来跑。三次保存，每次传进去的都是内存里的完整账本：

<!-- run -->
```java
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.util.ArrayList;
import java.util.List;

public class Main {
    static final Path FILE = Path.of("ledger.csv");
    static final String HEADER = "date,category,note,amount";

    static void save(List<String> entries) throws Exception {
        List<String> lines = new ArrayList<>();
        lines.add(HEADER);
        lines.addAll(entries);
        Files.write(FILE, lines, StandardCharsets.UTF_8,
                StandardOpenOption.CREATE, StandardOpenOption.APPEND);
    }

    public static void main(String[] args) throws Exception {
        Files.deleteIfExists(FILE);
        List<String> memory = new ArrayList<>();
        memory.add("2026-10-01,餐饮,早饭,-12.00");
        save(memory);
        memory.add("2026-10-01,交通,地铁,-3.00");
        save(memory);
        memory.add("2026-10-01,工资,日结,300.00");
        save(memory);

        List<String> lines = Files.readAllLines(FILE, StandardCharsets.UTF_8);
        long count = lines.stream().filter(line -> !line.equals(HEADER)).count();
        System.out.println("读回账目：" + count + " 条");
        lines.stream().filter(line -> !line.equals(HEADER)).forEach(System.out::println);
    }
}
```

```text
读回账目：6 条
2026-10-01,餐饮,早饭,-12.00
2026-10-01,餐饮,早饭,-12.00
2026-10-01,交通,地铁,-3.00
2026-10-01,餐饮,早饭,-12.00
2026-10-01,交通,地铁,-3.00
2026-10-01,工资,日结,300.00
```

我原来以为是 `load()` 读重了，或者 `list` 循环写错了。实际都不是：`load()` 只按行读一遍，问题在 `save()`。第一版 `save()` 把 `HEADER + 内存里的全部 entries` 追加到文件末尾：

```java
// 片段：第一版 CsvStore.save()
Files.write(file, lines, StandardCharsets.UTF_8,
        StandardOpenOption.CREATE, StandardOpenOption.APPEND);
```

第一次保存写 1 条，第二次写 2 条，第三次写 3 条；文件里留下 1+2+3=6 条数据行。`load()` 跳过三行 header，读回来就是 6 条。**重复不在读，在写：同一个列表保存两次，结果不一样。**

修法不是加去重，而是让一次 `save` 的结果只由传入的列表决定：先写同目录临时文件，再替换；不碰 `APPEND`。

```java
// 片段：修好后的 CsvStore.save()
Path temp = file.resolveSibling(file.getFileName() + ".tmp");
Files.write(temp, lines, StandardCharsets.UTF_8);
Files.move(temp, file, StandardCopyOption.REPLACE_EXISTING);
```

同一份列表连续保存两次，结果还是 3 条：

## 一条账目先定死

账本里的一条记录只有四个字段：日期、分类、备注、金额。这里用手写类，不用 `record`。`record` 在第 11、16 课先露过面，第 35 课专门讲；综合项目不靠一个还没展开的语法，字段、构造器、getter 都是第 05 课的内容。

```java
// Entry.java
import java.math.BigDecimal;
import java.time.LocalDate;

public final class Entry {
    private final LocalDate date;
    private final String category;
    private final String note;
    private final BigDecimal amount;

    public Entry(LocalDate date, String category, String note, BigDecimal amount) {
        if (date == null) {
            throw new IllegalArgumentException("日期不能为空");
        }
        if (category == null || category.isBlank()) {
            throw new IllegalArgumentException("分类不能为空");
        }
        if (category.indexOf('\n') >= 0 || category.indexOf('\r') >= 0) {
            throw new IllegalArgumentException("分类不能含换行");
        }
        if (amount == null) {
            throw new IllegalArgumentException("金额不能为空");
        }
        if (amount.signum() == 0) {
            throw new IllegalArgumentException("金额不能为 0");
        }
        String safeNote = note == null ? "" : note;
        if (safeNote.indexOf('\n') >= 0 || safeNote.indexOf('\r') >= 0) {
            throw new IllegalArgumentException("备注不能含换行");
        }
        this.date = date;
        this.category = category.trim();
        this.note = safeNote;
        this.amount = amount;
    }

    public LocalDate getDate() {
        return date;
    }

    public String getCategory() {
        return category;
    }

    public String getNote() {
        return note;
    }

    public BigDecimal getAmount() {
        return amount;
    }

    public boolean isIncome() {
        return amount.signum() > 0;
    }
}
```

金额用有符号的 `BigDecimal`：收入为正，支出为负，结余就是求和。校验放在构造器里，`new Entry(...)` 是唯一入口；`note == null` 收成空串，但含换行的字段直接拒绝，因为存储层按行读 CSV，允许换行会把一行拆成两行。

金额不能经过 `double`：

```text
double 加法：0.30000000000000004
字符串构造：0.3

equals 1.0/1.00：false
```

`0.1` 在二进制里是无限循环，`double` 只能存一个近似值。`new BigDecimal(0.1)` 会把这个近似值原样搬进来；`new BigDecimal("0.1")` 按十进制解析，才是账面上的 0.1。比较金额用 `compareTo(...) == 0`，不要用 `equals`，因为 `1.0` 和 `1.00` 的 scale 不同。

## 汇总不碰文件

`Summary` 只接收 `List<Entry>`，不读文件、不打印：

```java
// Summary.java
import java.math.BigDecimal;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

public final class Summary {
    private final BigDecimal income;
    private final BigDecimal expense;
    private final BigDecimal balance;
    private final Map<String, BigDecimal> byCategory;

    private Summary(BigDecimal income, BigDecimal expense, BigDecimal balance,
                    Map<String, BigDecimal> byCategory) {
        this.income = income;
        this.expense = expense;
        this.balance = balance;
        this.byCategory = byCategory;
    }

    public static Summary of(List<Entry> entries) {
        BigDecimal income = BigDecimal.ZERO;
        BigDecimal expense = BigDecimal.ZERO;
        Map<String, BigDecimal> byCategory = new TreeMap<>();
        for (Entry entry : entries) {
            if (entry.isIncome()) {
                income = income.add(entry.getAmount());
            } else {
                expense = expense.add(entry.getAmount().abs());
            }
            byCategory.merge(entry.getCategory(), entry.getAmount(), BigDecimal::add);
        }
        return new Summary(income, expense, income.subtract(expense), byCategory);
    }

    public BigDecimal getIncome() {
        return income;
    }

    public BigDecimal getExpense() {
        return expense;
    }

    public BigDecimal getBalance() {
        return balance;
    }

    public Map<String, BigDecimal> getByCategory() {
        return byCategory;
    }
}
```

一次循环同时算收入、支出和分类合计。分类用 `TreeMap`，输出顺序固定；它按字符串的 UTF-16 码元排序，不是拼音，所以「交通」在「工资」前面，「工资」又在「餐饮」前面。分类行保留符号：收入是正数，支出是负数；要看支出绝对值，就对金额再取 `abs()`。

## 存储层只做一件事

存储层是唯一碰文件的地方。先把 `APPEND` 去掉还不够：我把备注写成 `午饭,加饮料`，下一次启动读到的是一行五列：

```text
启动失败：账本内容有误：第 2 行列数不对：2026-10-26,餐饮,午饭,加饮料,-28.50
```

CSV 的逗号是分隔符，字段里出现逗号就必须加引号；字段里有引号，还要把引号写成两个。下面这版 `CsvStore` 写和读用同一套规则：

```java
// CsvStore.java
import java.io.IOException;
import java.math.BigDecimal;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;

public final class CsvStore {
    private static final String HEADER = "date,category,note,amount";

    private final Path file;

    public CsvStore(Path file) {
        this.file = file;
    }

    public List<Entry> load() throws IOException {
        List<Entry> entries = new ArrayList<>();
        if (Files.notExists(file)) {
            return entries;
        }
        List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
        for (int i = 0; i < lines.size(); i++) {
            String line = lines.get(i);
            if (line.isBlank() || line.equals(HEADER)) {
                continue;
            }
            entries.add(parse(line, i + 1));
        }
        return entries;
    }

    public void save(List<Entry> entries) throws IOException {
        List<String> lines = new ArrayList<>();
        lines.add(HEADER);
        for (Entry entry : entries) {
            lines.add(String.join(",",
                    entry.getDate().toString(),
                    escape(entry.getCategory()),
                    escape(entry.getNote()),
                    entry.getAmount().toPlainString()));
        }
        Path temp = file.resolveSibling(file.getFileName() + ".tmp");
        Files.write(temp, lines, StandardCharsets.UTF_8);
        Files.move(temp, file, StandardCopyOption.REPLACE_EXISTING);
    }

    private static String escape(String value) {
        if (value.indexOf(',') >= 0 || value.indexOf('"') >= 0) {
            return '"' + value.replace("\"", "\"\"") + '"';
        }
        return value;
    }

    private Entry parse(String line, int lineNumber) {
        List<String> parts;
        try {
            parts = split(line);
        } catch (IllegalArgumentException error) {
            throw new IllegalArgumentException("第 " + lineNumber + " 行：" + error.getMessage(), error);
        }
        if (parts.size() != 4) {
            throw new IllegalArgumentException("第 " + lineNumber + " 行列数不对：" + line);
        }
        try {
            return new Entry(LocalDate.parse(parts.get(0)), parts.get(1), parts.get(2),
                    new BigDecimal(parts.get(3)));
        } catch (RuntimeException error) {
            throw new IllegalArgumentException("第 " + lineNumber + " 行解析失败：" + line, error);
        }
    }

    private static List<String> split(String line) {
        List<String> parts = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean quoted = false;
        for (int i = 0; i < line.length(); i++) {
            char c = line.charAt(i);
            if (quoted) {
                if (c == '"') {
                    if (i + 1 < line.length() && line.charAt(i + 1) == '"') {
                        current.append('"');
                        i++;
                    } else {
                        quoted = false;
                    }
                } else {
                    current.append(c);
                }
            } else if (c == '"') {
                quoted = true;
            } else if (c == ',') {
                parts.add(current.toString());
                current.setLength(0);
            } else {
                current.append(c);
            }
        }
        if (quoted) {
            throw new IllegalArgumentException("引号没有闭合");
        }
        parts.add(current.toString());
        return parts;
    }
}
```

写出来的文件长这样：

```text
date,category,note,amount
2026-10-26,餐饮,"午饭,加饮料",-28.50
```

读的时候不能再用 `split(",")`：引号里的逗号不是分隔符，两个连续引号是一个字面引号。`split` 方法是一个小状态机，逐字符判断「当前在不在引号里」；写和读的规则必须成对，否则保存成功、重启失败。

`Files.write(temp, ...)` 只写临时文件，`Files.move(..., REPLACE_EXISTING)` 才替换原账本。写到一半失败时，原账本没被碰过；替换本身不承诺断电原子性，这一条留给「还差的」里说。

## 入口只负责读和分派

入口用第 14 课见过的 `BufferedReader`，不用 `Scanner`。`Scanner` 不在前面的课里，而且 `new Scanner(System.in)` 用平台默认字符集；这里要的是明确的 UTF-8。

```java
// Main.java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.math.BigDecimal;
import java.nio.charset.StandardCharsets;
import java.nio.file.Path;
import java.time.LocalDate;
import java.time.format.DateTimeParseException;
import java.util.ArrayList;
import java.util.List;

public class Main {
    private final Path file;
    private final CsvStore store;
    private final List<Entry> entries;
    private final BufferedReader reader;

    public Main(Path file, BufferedReader reader) throws IOException {
        this.file = file;
        this.store = new CsvStore(file);
        this.entries = new ArrayList<>(store.load());
        this.reader = reader;
    }

    public static void main(String[] args) {
        Path file = Path.of(args.length > 0 ? args[0] : "ledger.csv");
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(System.in, StandardCharsets.UTF_8))) {
            new Main(file, reader).run();
        } catch (IOException error) {
            System.out.println("启动失败：读不了 " + file + "：" + error.getMessage());
        } catch (IllegalArgumentException error) {
            System.out.println("启动失败：账本内容有误：" + error.getMessage());
        }
    }

    public void run() {
        System.out.println("记账本：add / list / summary / quit");
        while (true) {
            System.out.print("> ");
            String command;
            try {
                command = reader.readLine();
            } catch (IOException error) {
                System.out.println("读取输入失败：" + error.getMessage());
                return;
            }
            if (command == null) {
                return;
            }
            command = command.trim();
            try {
                switch (command) {
                    case "add" -> add();
                    case "list" -> list();
                    case "summary" -> summary();
                    case "quit", "exit" -> {
                        System.out.println("退出，共 " + entries.size() + " 条");
                        return;
                    }
                    case "" -> { }
                    default -> System.out.println("未知命令：" + command);
                }
            } catch (DateTimeParseException error) {
                System.out.println("输入有误：日期要写成 2026-10-26");
            } catch (IllegalArgumentException error) {
                System.out.println("输入有误：" + error.getMessage());
            } catch (IOException error) {
                System.out.println("读写失败：" + error.getMessage());
            }
        }
    }

    private void add() throws IOException {
        System.out.print("日期（如 2026-10-26）：");
        LocalDate date = LocalDate.parse(nextLine());
        System.out.print("分类（如 餐饮）：");
        String category = nextLine();
        System.out.print("备注：");
        String note = nextLine();
        System.out.print("金额（收入为正，支出为负）：");
        BigDecimal amount = new BigDecimal(nextLine());
        Entry entry = new Entry(date, category, note, amount);
        entries.add(entry);
        try {
            store.save(entries);
        } catch (IOException error) {
            entries.remove(entries.size() - 1);
            throw error;
        }
        System.out.println("已保存，当前 " + entries.size() + " 条");
    }

    private void list() {
        if (entries.isEmpty()) {
            System.out.println("还没有记录");
            return;
        }
        for (int i = 0; i < entries.size(); i++) {
            Entry entry = entries.get(i);
            System.out.printf("%3d  %s  %s  %10s  %s%n",
                    i + 1, entry.getDate(), entry.getCategory(),
                    entry.getAmount().toPlainString(), entry.getNote());
        }
    }

    private void summary() {
        Summary summary = Summary.of(entries);
        System.out.println("收入：" + summary.getIncome().toPlainString());
        System.out.println("支出：" + summary.getExpense().toPlainString());
        System.out.println("结余：" + summary.getBalance().toPlainString());
        summary.getByCategory().forEach((category, amount) ->
                System.out.println("  " + category + "：" + amount.toPlainString()));
    }

    private String nextLine() throws IOException {
        String line = reader.readLine();
        if (line == null) {
            throw new IllegalArgumentException("输入提前结束");
        }
        return line.trim();
    }
}
```

三个边界分开了：

- 启动时读账本失败，`main` 打印「启动失败」，不再把栈甩给用户；
- `add` 的输入错误（日期、金额、空分类）在命令循环里打印「输入有误」，回到 `>`；
- `store.save` 抛 `IOException` 时，先把刚加进内存的条目删掉，再交给循环打印「读写失败」；这样 `list` 不会显示一条没落盘的账。

`quit` 只打印「退出，共 N 条」，不说「已保存」。保存只发生在 `add` 里；如果最后一次保存失败，条目已经回滚，退出时不能再宣称保存成功。

## 自检：不碰文件

`SelfCheck` 只依赖 `Entry` 和 `Summary`，不创建文件：

```java
// SelfCheck.java
import java.math.BigDecimal;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;

public class SelfCheck {
    static void check(boolean condition, String message) {
        if (!condition) {
            throw new AssertionError(message);
        }
    }

    public static void main(String[] args) {
        List<Entry> sample = List.of(
                new Entry(LocalDate.of(2026, 10, 1), "工资", "工资", new BigDecimal("8000.00")),
                new Entry(LocalDate.of(2026, 10, 2), "餐饮", "午饭", new BigDecimal("-28.50")),
                new Entry(LocalDate.of(2026, 10, 3), "交通", "地铁", new BigDecimal("-6.00")));

        Summary summary = Summary.of(sample);
        check(summary.getIncome().compareTo(new BigDecimal("8000.00")) == 0, "收入算错");
        check(summary.getExpense().compareTo(new BigDecimal("34.50")) == 0, "支出算错");
        check(summary.getBalance().compareTo(new BigDecimal("7965.50")) == 0, "结余算错");
        check(Summary.of(new ArrayList<>()).getBalance().signum() == 0, "空账本结余应为 0");

        System.out.println("自测通过");
    }
}
```

这里不用 `assert` 关键字：它默认关闭，忘了加 `-ea` 就静默通过。`check` 在任何一次运行里都会执行，失败直接抛 `AssertionError`。四个点分别是纯收入、纯支出、结余关系、空账本；金额比较用 `compareTo`，不用 `equals`。

## 还差的

- 没有数据库和索引，每次 `add` 都把整本账重写一遍；账本大了会慢，也没有按月、按分类查询。
- 没有处理多进程或多线程同时写；临时文件名固定，两个进程会互相覆盖，也没有文件锁。
- CSV 只处理逗号和引号，字段里的换行被 `Entry` 拒绝；没有实现完整的多行字段解析，也没有导入银行流水。
- 没有测试框架；`SelfCheck` 只覆盖汇总的四个点，CSV 往返、I/O 失败回滚、并发都没测。
- `Files.move` 的替换没有加 `ATOMIC_MOVE`，也不保证跨文件系统或断电时原子；这里只做到「写临时文件失败时原账本不动」。
