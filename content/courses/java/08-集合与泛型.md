# 08 · 集合与泛型

## 这一课你要会

- 用 `List`、`Map`、`Set` 三种集合，知道各自按什么找东西；
- 说清泛型**只在编译期存在**，以及擦除带来的三个限制；
- 知道 `Arrays.asList` 与 `List.of` 的区别，避免"改不了"的意外。

## 为什么

数组定长，实际业务里几乎都要"能增删的列表"和"按名字查的表"。集合是 Java 里真正在用的容器。

泛型是集合的类型安全保证。不理解擦除，你会在"为什么不能 `new T()`""为什么 `instanceof List<String>` 不合法"上反复困惑。

## 讲解

### 三种集合，按"怎么找"排序

| 集合 | 找什么 | 典型用途 |
| --- | --- | --- |
| `List` | 按下标 / 顺序 | 有序列表，允许重复 |
| `Set` | "有没有" | 去重、判断存在 |
| `Map` | 按 key | 名字 → 值 |

常用实现：`ArrayList`（最常用）、`HashSet`、`HashMap`。

**接口优先**：声明写 `List<String> names = new ArrayList<>();`，不要把变量类型写成 `ArrayList`——以后换实现只改一处。

### 泛型写的是"里面装什么"

```text
List<String> names = new ArrayList<>();
names.add("小林");
String first = names.get(0);   // 不用强转
```

没有泛型时，取出来是 `Object`，每次都要强转，而且转错了在运行期才炸。泛型把这个检查提前到编译期。

**泛型不参与继承**：`List<String>` 不是 `List<Object>` 的子类型。想表达"某种元素的列表"用通配符 `List<?>`。

### 类型擦除

泛型参数**在编译后就消失了**。`List<String>` 与 `List<Integer>` 在运行时是同一个类 `List`。

三个直接限制：

1. 不能 `new T()`、不能 `new T[10]`；
2. 不能 `instanceof List<String>`（只能 `instanceof List`）；
3. 运行期无法知道一个空列表"本来装什么"。

这也是为什么 `new ArrayList<String>[]` 不合法——数组需要知道运行期类型，而泛型参数那时已经没了。

### 几个容易踩的 API

```text
Arrays.asList(1, 2, 3)   // 定长，set 可以，add/remove 抛异常
List.of(1, 2, 3)         // 完全不可变
new ArrayList<>(List.of(1, 2, 3))  // 要能改就再包一层
```

`Arrays.asList` 返回的是**原数组的视图**：改列表会改数组，改数组列表也变。这在解算法题时是常见 bug。

### 遍历时不能删

```text
for (String name : names) {
    if (name.isEmpty()) {
        names.remove(name);   // ConcurrentModificationException
    }
}
```

要删就用 `iterator.remove()`，或者 `names.removeIf(String::isEmpty)`，或者构建新列表。

    public static void main(String[] args) {

        names.add("小林");
        names.add("小周");
        names.add("小林");
        System.out.println(names);
        System.out.println(names.size());
        System.out.println(names.contains("小周"));

        Set<String> unique = new TreeSet<>(names);
        System.out.println(unique);

        Map<String, Integer> scores = new java.util.TreeMap<>();
        scores.put("语文", 90);
        scores.put("数学", 85);
        scores.put("语文", 95);
        System.out.println(scores.get("语文"));
        System.out.println(scores.getOrDefault("英语", 0));
        System.out.println(scores.size());

        for (Map.Entry<String, Integer> entry : scores.entrySet()) {
            System.out.println(entry.getKey() + "=" + entry.getValue());
        }

        List<Integer> fixed = List.of(1, 2, 3);
        try {
            fixed.add(4);
        } catch (UnsupportedOperationException error) {
            System.out.println("List.of 不可变");
        }

        List<Integer> mutable = new ArrayList<>(fixed);
        mutable.add(4);
        System.out.println(mutable);

        names.removeIf("小林"::equals);
        System.out.println(names);
    }
}

## 常见误区

### 误区：运行期能拿到 `List<String>` 的类型参数

**你以为**：泛型和 C# 一样是具体化的。
**其实**：Java 泛型在编译期被擦除，运行时不保留类型实参。
**怎么验证**：`List<String>` 与 `List<Integer>` 的 `getClass()` 是同一个类。

### 误区：`Arrays.asList` 得到的是普通列表

**你以为**：可以随便 add/remove。
**其实**：它返回定长视图，`add` 抛 `UnsupportedOperationException`，而且改它会改到原数组。

### 误区：`List.of` 只是更短的写法

**你以为**：功能一样。
**其实**：它完全不可变（连 `set` 都不行），也不接受 `null` 元素。

## 小结

按"怎么找"选集合：下标用 `List`、存在性用 `Set`、键值用 `Map`。泛型只在编译期。擦除导致不能 `new T()`、不能 `instanceof List<String>`。遍历时不要删，用 `removeIf`。
