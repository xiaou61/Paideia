# 02 · 运算符与条件

## 这一课你要会

- 分清 `==` 在基本类型和 `String` 上的两种含义；
- 用 `equals` 比较字符串内容，并知道为什么 `"abc" == new String("abc")` 是 `false`；
- 用 `if / else if / else` 与 `switch` 表达分支。

## 为什么

Java 里最经典、也最难自察的一个 bug 就在这里：两个字符串看起来完全一样，`==` 却返回 `false`。它不报错、不抛异常，只是静静走错分支。

理解它需要一句话：**`==` 比的是"是不是同一块东西"，`equals` 比的才是"内容一样不一样"**。这一课把这句话讲透。

## 讲解

### 算术与自增

`+ - * / %` 与 Python 相同，整数除法同样丢小数。

`i++` 与 `++i` 平时一样，但用在表达式里不同：`a = i++` 先用再加，`a = ++i` 先加再用。**不要在同一行里混用**，读代码的人会算错。

### `==` 的两种含义

- **基本类型**（`int`、`double`、`boolean`…）：比的是值，`3 == 3` 是 `true`；
- **引用类型**（`String`、数组、对象）：比的是"是不是同一个对象"。

字符串字面量会被放进字符串常量池，所以 `"abc" == "abc"` 常常是 `true`——那是池化，不是语言保证。用 `new String("abc")` 造出来的就不在同一个位置了，于是 `==` 得 `false`。

**结论：字符串一律用 `equals`**。要忽略大小写用 `equalsIgnoreCase`。

判空要注意顺序：`name.equals("abc")` 在 `name` 为 `null` 时会 `NullPointerException`。稳妥写法是把常量放前面：`"abc".equals(name)`。

### 布尔运算

`&&`、`||`、`!`——与 Python 的 `and/or/not` 对应。

`&&` 会短路：`if (user != null && user.isActive())` 左边是 `false` 时右边不执行，所以不会空指针。**Java 里这条比 Python 更常用**，因为 Java 有 `null`。

### `switch`

```text
switch (day) {
    case 1, 2, 3, 4, 5 -> System.out.println("工作日");
    case 6, 7 -> System.out.println("周末");
    default -> System.out.println("不认识的数字");
}
```

箭头形式不会"贯穿"（不需要 `break`）。老的冒号形式会贯穿，忘了 `break` 会连续执行下面的分支——那是 Java 历史上最著名的 bug 来源之一。**新代码用箭头形式**。

### 跑一遍

<!-- run -->
```java
public class Main {
    public static void main(String[] args) {
        String a = "abc";
        String b = new String("abc");

        System.out.println(a == b);
        System.out.println(a.equals(b));
        System.out.println(a.equalsIgnoreCase("ABC"));

        String maybeNull = null;
        System.out.println("abc".equals(maybeNull));

        int score = 78;
        if (score >= 90) {
            System.out.println("优秀");
        } else if (score >= 60) {
            System.out.println("及格");
        } else {
            System.out.println("不及格");
        }

        int day = 6;
        switch (day) {
            case 1, 2, 3, 4, 5 -> System.out.println("工作日");
            case 6, 7 -> System.out.println("周末");
            default -> System.out.println("不认识的数字");
        }

        System.out.println(7 / 2);
        System.out.println(7 % 2);
    }
}
```

## 常见误区

### 误区：两个字符串内容相同，用 `==` 就是 true

**你以为**：`==` 就是比较内容。
**其实**：引用类型上它比的是"是不是同一个对象"。字面量池化会让它偶尔看起来对，那是陷阱。
**怎么验证**：`"abc" == new String("abc")`，打印结果。

### 误区：`equals` 和 `==` 只是写法不同

**你以为**：随便用。
**其实**：混用会让比较在"看起来一样"的字符串上返回 `false`，而且不报错。

### 误区：`switch` 可以是任何类型

**你以为**：跟 Python 的 `match` 一样什么都能塞。
**其实**：`switch` 支持整数、枚举、字符串、字符，不支持 `long`、`double`、`boolean`。

## 小结

基本类型用 `==` 比值，引用类型用 `equals` 比内容。常量放前面判空。`&&` 短路可以防空指针。新代码用箭头 `switch`。
