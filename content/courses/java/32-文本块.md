# 32 · 文本块

## 这一课你要会

- 用 `"""` 写多行字符串，不再靠 `\n` 拼接；
- 说清"公共缩进会被去掉"这条规则；
- 知道文本块**不能插值**，以及它适合写什么。

## 为什么

在文本块之前，写一段 JSON 或 SQL 是这样：

```text
String json = "{\n" +
        "  \"id\": 1024,\n" +
        "  \"name\": \"小林\"\n" +
        "}";
```

每一行都要转义引号、补 `\n`、拼 `+`。改一个字段要在三处对齐，漏一个引号就编译不过。

文本块（Java 15 正式）让你把内容**原样**贴进去：换行就是换行，双引号不用转义。

## 讲解

### 三个引号，内容原样

<!-- run -->
```java
public class Main {
    public static void main(String[] args) {
        String json = """
                {
                  "id": 1024,
                  "name": "小林"
                }
                """;

        System.out.println(json);
        System.out.println(json.contains("\"id\": 1024"));
    }
}
```
```text
{
  "id": 1024,
  "name": "小林"
}

true
```

注意两点：

- 里面写 `"id"` 不用转义；只有连续三个引号 `"""` 本身才需要转义；
- 输出里 `{` 顶格、`"id"` 缩进两格——**不是**源码里的八格。文本块会剥掉公共缩进。

### 缩进规则：以最小缩进为基准

编译器把所有非空行（以及结尾的 `"""` 那一行）的缩进放在一起，取**最小值**，然后从每一行开头去掉这么多空格。

所以下面两种写法输出不同：

```text
// 结尾的 """ 顶格 → 最小缩进是 0 → 四个空格全保留
String sql = """
    SELECT *
    FROM users
""";

// 结尾的 """ 缩进四格 → 最小缩进是 4 → 全部剥掉
String sql = """
    SELECT *
    FROM users
    """;
```

第一种会在每行前留下四个空格。它不报错，只是输出悄悄多了空格——用 `replace("\n", "|")` 打印出来才看得见。

### 结尾的换行

文本块的最后一个换行**属于内容**。上面 `json` 的末尾有一个 `\n`，`println` 又加一个，所以输出里 `}` 和 `true` 之间空了一行。

不想要结尾换行，就把结尾的 `"""` 紧跟在内容后面（同一行）：

```text
String text = """
        hello""";
```

### 它不能插值

文本块**只是字符串字面量的另一种写法**，没有 `${name}` 这种插值。要拼变量还是用 `+`、`String.format`、`formatted`：

```text
String sql = """
        SELECT * FROM users WHERE id = %d
        """.formatted(id);
```

（字符串模板在 Java 21 是预览特性，后续被撤回，别在生产代码里依赖。）

### 什么时候适合用

- SQL、JSON、HTML/XML 片段；
- 测试里的期望输出；
- 带格式的报错信息。

不适合：一段到处都要拼变量的长文本——那会变成很多 `%s`，比 `+` 更难读。

## 常见误区

### 误区：文本块会自动去掉所有前导空格

**你以为**：不管怎么缩进，输出都是顶格。
**其实**：只去掉**公共**缩进。某一行比别的行多缩进，多出来的部分会保留——这正好用来写代码块里的层级。

### 误区：文本块能做字符串插值

**你以为**：像 Kotlin/JS 的模板字符串。
**其实**：不能。变量还是要 `+` 或 `formatted`。别把预览特性的字符串模板当成正式功能。

### 误区：文本块里的引号完全不用管

**你以为**：所有引号都免转义。
**其实**：单个 `"` 不用转义，但连续三个 `"""` 会提前结束文本块，必须写成 `\"""`。

## 小结

文本块让多行文本原样进代码：内容里的换行就是换行，单引号不用转义。缩进按最小值统一剥掉，结尾换行属于内容，且不支持插值。适合 SQL、JSON 和测试期望值。
