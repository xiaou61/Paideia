# 05 · 类与对象

## 这一课你要会

- 写带字段、构造器、方法的类，并用 `new` 创建对象；
- 用 `private` + 访问方法做封装，说清为什么字段不该公开；
- 知道 `final` 只锁引用，不锁对象内部。

## 为什么

Java 是"一切都要放进类里"的语言。不掌握类，你连一个像样的工具都写不出来——上一课的方法全在一个 `Main` 里，写到十几个就开始乱。

这一课的重点不是语法，是**边界**：哪些字段该藏起来、构造器该保证什么、`final` 到底保证了什么。

## 讲解

### 最小可用的类

```text
public class Student {
    private final String name;
    private int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    public String getName() {
        return name;
    }

    public void addScore(int delta) {
        this.score += delta;
    }

    public int getScore() {
        return score;
    }
}
```

三件事：

1. **字段默认 private**，外面通过方法访问；
2. **构造器与类同名、没有返回类型**；
3. **`this` 区分字段与参数**：`this.name = name` 左边是字段，右边是参数。

### 封装不是形式主义

字段公开时，任何代码都能把它改成任意值：

```text
student.score = -1000;   // 没人拦住
```

改成 `private` 并在方法里校验：

```text
public void addScore(int delta) {
    if (delta < 0) {
        throw new IllegalArgumentException("加分不能为负");
    }
    this.score += delta;
}
```

**这才是封装的用途**：把"什么值合法"写在一个地方，而不是散在调用方。

### `final` 不等于不可变

```text
private final List<String> tags = new ArrayList<>();
```

`final` 只保证"这个字段的引用不再指向别的对象"。`tags.add("x")` 完全合法——**对象内部还能改**。

真要不可变，得用不可变类型（如 `List.of(...)`）或者不暴露修改方法。

### `equals` 与 `hashCode` 要成对重写

默认的 `equals` 比引用，所以两个内容相同的对象不相等。要按内容比较就自己重写 `equals`；而**重写 `equals` 就必须一起重写 `hashCode`**——否则放进 `HashMap` / `HashSet` 会找不到自己。

### `toString` 值得重写

不重写时打印得到 `Student@1b6d3586`。重写成一句能看懂的，排错省很多时间。

### 跑一遍

<!-- run -->
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Objects;

public class Main {

    static class Student {
        private final String name;
        private int score;
        private final List<String> tags = new ArrayList<>();

        Student(String name, int score) {
            this.name = name;
            this.score = score;
        }

        void addScore(int delta) {
            if (delta < 0) {
                throw new IllegalArgumentException("加分不能为负");
            }
            this.score += delta;
        }

        void tag(String value) {
            tags.add(value);
        }

        @Override
        public String toString() {
            return "Student{name=" + name + ", score=" + score + ", tags=" + tags + "}";
        }

        @Override
        public boolean equals(Object other) {
            if (this == other) {
                return true;
            }
            if (!(other instanceof Student student)) {
                return false;
            }
            return score == student.score && Objects.equals(name, student.name);
        }

        @Override
        public int hashCode() {
            return Objects.hash(name, score);
        }
    }

    public static void main(String[] args) {
        Student a = new Student("小林", 80);
        a.addScore(10);
        a.tag("python");
        a.tag("java");
        System.out.println(a);

        Student b = new Student("小林", 90);
        System.out.println(a.equals(b));
        System.out.println(a == b);

        try {
            a.addScore(-5);
        } catch (IllegalArgumentException error) {
            System.out.println("被拦住：" + error.getMessage());
        }
    }
}
```
```text
Student{name=小林, score=90, tags=[python, java]}
true
false
被拦住：加分不能为负
```

注意 `a.equals(b)` 是 `true`（内容相同），而 `a == b` 是 `false`（不同对象）——与上一课字符串那条规则完全一致。

## 常见误区

### 误区：`final` 对象完全不可变

**你以为**：加了 final 就改不动了。
**其实**：只锁引用。对象内部状态照改不误。
**怎么验证**：`final List` 之后 `add` 一个元素，编译通过。

### 误区：字段公开比较方便，反正是自己的代码

**你以为**：省得写一堆 getter/setter。
**其实**：公开字段等于把"什么值合法"交给每个调用方。一处写错就污染整个对象。
**怎么验证**：搜索一次 `\.balance\s*=` 看有多少地方在直接改它。

### 误区：getter/setter 就是封装

**你以为**：字段 private + 一对 get/set 就叫封装了。
**其实**：如果 setter 什么都不校验，等于把公开字段换个写法。封装是**约束**，不是方法名。

## 小结

字段默认 private，校验写在方法里。构造器与类同名、无返回类型。`final` 只锁引用。重写 `equals` 必须一起重写 `hashCode`。
