# 04 · 数组与字符串

## 这一课你要会

- 建数组、取长度、遍历、用 `Arrays` 工具类；
- 说清 `String` 为什么不可变，以及它带来的两个直接后果；
- 知道数组协变会让"看起来安全的赋值"在运行期炸。

## 为什么

数组是 Java 最基础的数据容器，字符串是最高频的类型。两者都有"看起来简单、细节致命"的地方：

- 数组长度固定，越界抛异常；
- 数组协变：`Object[]` 能接 `String[]`，但往里塞别的类型会在运行期炸；
- 字符串不可变，所以"修改"其实是造新串，循环里尤其要小心。

## 讲解

### 数组的三种写法

```text
int[] numbers = new int[3];              // 默认值 0
int[] fixed = {1, 2, 3};                 // 直接初始化
String[] names = new String[]{"a", "b"}; // 完整写法
```

长度用 `numbers.length`（**不是方法，不带括号**）。下标从 0 到 `length - 1`，越界抛 `ArrayIndexOutOfBoundsException`——这是运行期异常，编译期不会提醒。

**数组长度不可变**。要能增删就用 `ArrayList`（第 8 课）。

### `Arrays` 工具类

```text
import java.util.Arrays;

Arrays.toString(numbers)   // 打印数组内容（直接打印数组只会得到 [I@1b6d3586）
Arrays.sort(numbers)       // 原地排序
Arrays.copyOf(numbers, 5)  // 复制（不够的补默认值）
Arrays.equals(a, b)        // 比较内容
```

`==` 比较两个数组永远比的是引用，内容比较必须用 `Arrays.equals`。

### 字符串不可变

```text
String text = "abc";
text.toUpperCase();       // 返回新串，text 不变
text = text.toUpperCase(); // 接住才变
```

两个直接后果：

1. 任何"修改"都返回新对象，所以循环里 `text = text + x` 很费；
2. **字符串可以安全共享**——把它交给别的代码，不用担心被改。

### 常用方法

| 方法 | 作用 |
| --- | --- |
| `length()` | 字符数（**带括号**，与数组不同） |
| `charAt(i)` | 取第 i 个字符 |
| `substring(a, b)` | 左闭右开切 |
| `indexOf` / `contains` | 找位置 / 判断包含 |
| `split(regex)` | **按正则**切分 |
| `strip()` | 去掉两端空白 |
| `isEmpty()` / `isBlank()` | 空串 / 只有空白 |

`split` 的参数是**正则表达式**，不是普通字符串。点号 `.` 在正则里是"任意字符"，所以按点切要写 `"\\."`。

### 数组协变

```text
Object[] objects = new String[]{"a"};
objects[0] = 1;      // 编译通过，运行期抛 ArrayStoreException
```

数组在运行期知道自己的真实类型，写入时做检查。这是 Java 数组的一个历史设计，和泛型（第 8 课）的方向相反。

### 跑一遍

<!-- run -->
```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] numbers = {3, 1, 2};
        System.out.println(numbers.length);
        System.out.println(Arrays.toString(numbers));

        Arrays.sort(numbers);
        System.out.println(Arrays.toString(numbers));

        String text = "  Hello World  ";
        System.out.println(text.strip());
        System.out.println(text.strip().toUpperCase());
        System.out.println(text.strip().substring(0, 5));
        System.out.println(text.contains("World"));
        System.out.println(text.strip().split(" ").length);
        System.out.println("a,b,c".split(",").length);
        System.out.println("a.b.c".split("\\.").length);
        System.out.println("".isBlank());

        String original = "abc";
        original.toUpperCase();
        System.out.println(original);
    }
}
```

## 常见误区

### 误区：`String[]` 可以当 `Object[]` 用，往里放任何对象都安全

**你以为**：既然能赋值给 `Object[]`，那就能放任意对象。
**其实**：数组在运行期检查真实类型，放错的类型抛 `ArrayStoreException`。
**怎么验证**：按上面三行试一次，看异常类型。

### 误区：`String` 的方法会改原串

**你以为**：`toUpperCase()` 是原地转换。
**其实**：不可变类型，所有方法返回新串。

### 误区：`==` 可以比较两个数组的内容

**你以为**：内容一样就相等。
**其实**：`==` 比引用。内容比较用 `Arrays.equals`。

## 小结

数组定长，`length` 不带括号；`String` 是 `length()` 带括号。字符串不可变，方法要接返回值。`split` 吃正则。数组协变的赋值只在运行期炸——别把数组当父类型容器。
