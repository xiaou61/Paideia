# 01 · 编译运行与变量

## 这一课你要会

- 用 `javac` 编译、用 `java` 运行一个 `.java` 文件；
- 说清八种基本类型，以及为什么 `int` 除以 `int` 得不到小数；
- 读懂最常见的两种编译错误：缺分号、类型不匹配。

## 为什么

Java 的第一道门是"我的代码为什么跑不起来"。它和 Python 最大的区别是：**写完之后要先编译**。

编译这一步不理解，后面所有报错你都分不清是"写错了"还是"还没编译"。

## 讲解

### 两个命令，各干一件事

```text
javac Main.java    # 编译：把源码变成 Main.class（字节码）
java Main          # 运行：让 JVM 执行 Main.class
```

注意 `java` 后面**不加 `.class`**，写的是类名。

一个文件里通常只有一个 `public class`，而且**类名必须和文件名一致**：`Main.java` 里是 `public class Main`。不一致会报 `class X is public, should be declared in a file named X.java`。

### `main` 方法是入口

```text
public static void main(String[] args)
```

每个词都有用：

| 部分 | 含义 |
| --- | --- |
| `public` | 谁都能调用（JVM 需要） |
| `static` | 不用创建对象就能调用 |
| `void` | 不返回值 |
| `main` | 固定名字 |
| `String[] args` | 命令行参数 |

**少一个词就启动不了**，而且报错不一定直观（`Main method not found`）。

### 八种基本类型

| 类型 | 占几字节 | 范围 / 用途 |
| --- | --- | --- |
| `byte` | 1 | -128 ~ 127 |
| `short` | 2 | -32768 ~ 32767 |
| `int` | 4 | 约 ±21 亿（最常用） |
| `long` | 8 | 很大，字面量要加 `L` |
| `float` | 4 | 小数，字面量加 `f` |
| `double` | 8 | 小数，默认（最常用） |
| `char` | 2 | 单个字符，用单引号 `'a'` |
| `boolean` | 1 | `true` / `false` |

`String` **不是**基本类型，它是类，但用起来像基本类型。区别在于：`String` 是引用类型，这一点在下一课讲 `==` 时会变成一个大坑。

### 整数除法会丢小数

`7 / 2` 在两个都是 `int` 时得到 `3`，不是 `3.5`。要小数就让其中一个是 `double`：`7 / 2.0` 或 `(double) 7 / 2`。

### 变量要先声明类型

```text
int age = 18;
double score = 92.5;
String name = "小林";
boolean passed = true;
```

**每条语句以分号结尾**。忘了分号是最常见的第一个编译错误。

### 跑一遍

<!-- run -->
```java
public class Main {
    public static void main(String[] args) {
        int age = 18;
        double score = 92.5;
        String name = "小林";
        boolean passed = score >= 60;

        System.out.println("你好，" + name);
        System.out.println("年龄：" + age + "，分数：" + score + "，及格：" + passed);

        System.out.println(7 / 2);
        System.out.println(7 / 2.0);
        System.out.println(10 % 3);

        int big = 2_000_000_000;
        System.out.println(big + 1);
    }
}
```
```text
你好，小林
年龄：18，分数：92.5，及格：true
3
3.5
1
2000000001
```

最后一行用下划线分隔数字，只是给人看的，不影响值。

### 两种最常见的编译错误

```text
error: ';' expected
```

少分号。报错行号指向"它期待分号的地方"，通常就在上一行末尾漏了。

```text
error: incompatible types: possible lossy conversion from double to int
```

把 `double` 塞进 `int`。Java 不允许隐式丢掉精度，要么改类型，要么显式写 `(int)`（会截断小数）。

## 常见误区

### 误区：`java Main.java` 是运行 Java 的标准方式

**你以为**：直接跑源码，像 Python 那样。
**其实**：标准流程是先 `javac` 再 `java`。新版 JDK 支持直接 `java Main.java`（单文件源码模式），但那只适合试一小段，编译错误的位置与项目结构都不一样。

### 误区：`int` 和 `long` 都差不多，随便用

**你以为**：反正都存整数。
**其实**：`int` 上限约 21 亿，超过会**静默回绕成负数**，不报错。时间戳、字节数这类值必须用 `long`，字面量记得加 `L`。

### 误区：类名可以和文件名不同

**你以为**：随便起。
**其实**：`public class` 的名字必须等于文件名。不一致直接编译失败。

## 小结

`javac` 编译、`java` 运行，类名与文件名要一致。`main` 的五个部分缺一不可。整数除法丢小数。编译错误先看最后一行。
