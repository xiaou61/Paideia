# 01 · 编译运行与变量

## 第一个报错：类名后面加了 .class

装好 JDK，写完第一个文件，编译通过了，然后运行失败：

```text
$ javac Main.java
$ java Main.class
Error: Could not find or load main class Main.class
Caused by: java.lang.ClassNotFoundException: Main.class
```

`javac` 一声不响（它成功了），`java` 却找不到类。

原因就一个字：`java` 后面写的是**类名**，不是文件名。

```text
$ java Main
hi
```

`javac` 产出的是 `Main.class`，但 JVM 找的是「叫 `Main` 的类」——它自己会去补 `.class`。你手动加上去，它就去加载一个名叫 `Main.class` 的类，当然不存在。

这两条命令的分工就是这一课的第一件事：

```text
javac Main.java    # 编译：源码 → Main.class（字节码）
java Main          # 运行：让 JVM 执行 Main 这个类
```

但它带来的第二个坑更常见：**改了代码忘了重新编译**。`java Main` 跑的是磁盘上那个 `.class`，不是你刚改的 `.java`。改了没反应时先问自己一句：编译过了吗？

一个文件里通常只有一个 `public class`，名字必须和文件名一致。不一致时编译器说得很直白：

```text
Main.java:1: error: class Hello is public, should be declared in a file named Hello.java
```

## main 方法：哪几个词是必须的

```java
public static void main(String[] args)
```

| 部分 | 含义 | 能不能换 |
| --- | --- | --- |
| `public` | JVM 要能从外面调用 | 不能省 |
| `static` | 不用创建对象就能调用 | 不能省 |
| `void` | 不返回值 | 不能省 |
| `main` | 固定名字 | 不能改 |
| `String[] args` | 命令行参数 | **形状要 `String[]`，名字随便** |

最后一行最容易误会。`args` 只是个参数名，改成 `whatever` 照样能启动：

```java
public static void main(String... whatever)   // 也合法，String... 就是 String[]
```

我实测过，`java V` 正常打印 `ok`。所以「`main` 的五个部分缺一不可」这句话是错的——**缺的是 `public static void main` 和 `String[]` 这个形状**，不是那个名字。

少写 `static` 会得到：

```text
Error: Main method is not static in class Main, please define the main method as:
   public static void main(String[] args)
```

## 读完报错的第一行，而不是最后一行

我最开始读报错的方式是错的：往上翻到 `error` 附近，找最后一句。

漏一个分号时，javac 的输出是这样：

```text
MissingSemi.java:3: error: ';' expected
        int x = 1
                 ^
1 error
```

**最后一行只是 `1 error`，没有信息量。**真正的定位在第一条 `error:`——`文件:行号`，加上下面那行源码和 `^` 指出的位置。

而且「缺分号通常是在上一行末尾漏了」这个经验也不可靠。上面这个例子里 `^` 就指在同一行的 `1` 后面：编译器在读到换行时才觉得该有分号，于是报到这一行。

所以读报错的顺序是：

1. 第一条 `error:`（warning 可以先不看）；
2. `文件:行号`，直接跳过去；
3. `^` 指的位置，看那里缺了什么；
4. 改完重新编译，再看下一条——**不要一次改五处**，新错误会互相掩盖。

## 八种基本类型

| 类型 | 大小 | 范围 / 用途 |
| --- | --- | --- |
| `byte` | 1 字节 | -128 ~ 127 |
| `short` | 2 字节 | -32768 ~ 32767 |
| `int` | 4 字节 | -2147483648 ~ 2147483647（最常用） |
| `long` | 8 字节 | 更大；超出 int 范围的**字面量**要加 `L` |
| `float` | 4 字节 | 小数，字面量加 `f` |
| `double` | 8 字节 | 小数，默认类型 |
| `char` | 2 字节 | 单个字符，单引号 `'a'` |
| `boolean` | **规范未规定** | `true` / `false` |

最后一行值得说清楚：Java 语言规范只规定 `boolean` 的取值，**没有规定它占几个字节**；JVM 规范里单个 `boolean` 变量通常按 1 字节处理，`boolean[]` 在 HotSpot 上常见是每个元素 1 字节，但那是实现细节，不是你能依赖的承诺。写 `boolean` 时别在字节数上做假设。

`long` 那条也要收窄：`long t = 100;` 完全合法，`100` 是 `int` 字面量自动拓宽过去的。只有**超出 int 范围**时才必须加 `L`：

```java
long t = 3000000000L;    // 不加 L：integer number too large
long ok = 100;           // 合法，int 拓宽成 long
```

## int 溢出：两种不同的表现

这一条我原来写错过，值得单独说。**「超出 int 范围」有两种情况，报错方式完全不同：**

```java
int c = 2147483648;      // 字面量太大
```

```text
Big.java:1: error: integer number too large
```

编译器当场拒绝，因为它连这个值都装不进 `int`。

但**运算**溢出不会报错，它会静默回绕：

```java
int max = Integer.MAX_VALUE;
System.out.println(max + 1);      // -2147483648
```

`2147483647 + 1` 变成负数，没有异常、没有警告。如果代码里是 `+1` 算出来的（时间戳、字节数、计数器），你就得到一个负数。这类值一律用 `long`。

注意 `2_000_000_000 + 1` 不会溢出——它离上限还有 14 亿。下划线的位置也不影响值，纯粹给人看的。

## 整数除法会丢小数

```text
7 / 2      → 3      （两个 int，整除，直接截掉小数，不四舍五入）
7 / 2.0    → 3.5    （有 double 参与，结果就是 double）
10 % 3     → 1      （取余）
```

需要小数时，让其中一个变成小数：写 `2.0`，或者强转 `(double) 7 / 2`。`7 / 2 * 1.0` 是错的——先整除得 3，再乘 1.0 得 3.0，小数早就丢了。

## String 不是基本类型

`String` 是类，属于引用类型。它有三个和 `int` 完全不同的性质：

- 有方法（`name.length()`、`name.toUpperCase()`）；
- 可以是 `null`（`String name = null;` 合法，`int age = null;` 编译不过）；
- 用 `==` 比的是「是不是同一个对象」，不是内容——这是下一课的大坑。

## 跑一遍

<!-- run -->
```java
public class Main {
    public static void main(String[] args) {
        int age = 18;
        double score = 92.5;
        String name = "小林";
        boolean passed = score >= 60;

        System.out.println("你好，" + name);
        System.out.println("年龄：" + age + "，分数：" + score + "，及格：" + passed);

        System.out.println(7 / 2);
        System.out.println(7 / 2.0);
        System.out.println(10 % 3);

        int big = 2_000_000_000;
        System.out.println(big + 1);
    }
}
```
```text
你好，小林
年龄：18，分数：92.5，及格：true
3
3.5
1
2000000001
```

注：`score >= 60` 里的比较运算在下一课讲，这里先照抄。输出最后一行是 `2000000001`——注意它**没有溢出**，因为离 `int` 上限还差 14 亿；`Integer.MAX_VALUE + 1` 才会变成负数。
