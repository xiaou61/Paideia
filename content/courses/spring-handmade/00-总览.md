# 手写一个迷你 Spring

这条线是 **Spring 从零开始**（20 课）的实战版。

课程里是"看别人怎么写"，这里是"你自己写"。五关各给你一个**只读的测试入口** `TestMain.java`，你只改 `Main.java`，把测试跑绿。

## 为什么手写一遍

Spring 的多数解释是"它就是这么做的"，听完你还是不会判断"我的注解为什么不生效"。

手写过一次容器之后，你会知道"注入"就是反射找构造器参数；手写过一次动态代理之后，你会知道"自调用失效"不是框架的怪癖，而是代理模式的必然；手写过一次事务边界之后，你会知道"吞掉异常就不回滚"是从"切面只能看见穿出边界的异常"推出来的。

这三条，比背十个注解管用。

## 五关怎么排

- **第 1 关 容器**：反射造对象、按类型注入、单例。对应课程第 5–6 课。
- **第 2 关 作用域与生命周期**：单例 / 原型、初始化回调、逆序销毁。对应第 8 课。
- **第 3 关 路由**：注解式路由的底层——一张表加两次判断（404 与 405）。对应第 1 课。
- **第 4 关 代理**：`java.lang.reflect.Proxy` 实现前后置通知，并让"自调用不经过代理"成为断言。对应第 10–11 课。
- **第 5 关 事务**：快照、回滚、吞异常、自调用四条断言。对应第 12 课。

## 判题方式

和 **Java 项目实战** 一样：

| 形态 | 你交什么 |
| --- | --- |
| SQL 实战 | 一条查询 |
| 调试实战 | 修好的单文件 |
| **本线** | **一个可以编译运行的小项目（多文件）** |

`TestMain.java` 是只读的——它由服务端固定提供，与你自己的文件一起编译。所以你没法"改测试让它通过"。

**你的文件固定叫 `Main.java`，里面的 `public class` 必须是 `Main`。** 其余类写在同一个文件里，用**包级私有**（不加 `public`），这样 `TestMain` 才能看见它们。

通关判据：点「运行」，固定入口打印 `ALL PASS`。失败时它会逐条打印 `FAIL <哪一项> -> <具体原因>`。

## 常见误区

### 误区：先看答案再动手，效率更高

**你以为**：看懂答案等于会了。
**其实**：这五关的难点全是"某个东西为什么必须这么写"——比如第 5 关的 `selfCall` 必须**不**包事务。看懂这一句只要三秒，但你还是会在下一次遇到自调用失效时愣住。手写一遍才有判断力。

### 误区：跑绿了就算学会了

**你以为**：`ALL PASS` 就是终点。
**其实**：每关都有一个"为什么"是断言测不到的：第 1 关为什么两阶段能解循环依赖、第 3 关为什么 405 要单独返回、第 4 关为什么代理修不了自调用。跑绿只是入场券。

### 误区：这几关是玩具，对真实项目没用

**你以为**：手写的容器不如 Spring。
**其实**：它们做的事和 Spring 一样，只是少了健壮性（无循环依赖检测、无生命周期钩子的完整顺序、无并发安全）。**少的是工程量，不是原理。**你在真实项目里判断"这个注解为什么没生效"用的就是这些原理。

## 小结

五关，一条链：容器造对象 → 作用域决定几个 → 路由表把请求派给谁 → 代理在调用前后插入行为 → 事务就是那个行为的一个特例。

配套课程是 **Spring 从零开始**（20 课，讲原理与用法）；深入阅读在 **Spring** 那 8 篇里。
