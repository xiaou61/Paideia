## 这条线是干什么的

这条线不教你训练模型，也不比较哪个框架好用。它回答的是**把大模型从"聊天框"变成"能干活的程序"时，真正会卡住你的问题**：

- 一次调用答不好，是因为模型不行，还是因为任务本来就需要多步？
- 模型怎么知道该调哪个工具、传什么参数？
- 为什么同一个问题，第二轮它就"忘了"第一轮说过什么？
- 它答得挺像回事，但怎么证明它真的变好了？
- 上线之后，账单和事故会从哪里来？

## 一个前提：你已经会调 API

这条线假设你已经能用某个大模型 API 发一次请求、拿到回复。**所有结论都以"用 API 做产品"为背景**，不涉及预训练、微调、GPU 集群，也不要求你会某个具体框架。

如果你还没建立"模型看到的是什么"这个基本认知，建议先读「人工智能」那条线的第一篇（token 与上下文）——本线后面讲上下文工程时会反复用到它。

## 十三篇的走法

**第一部分：先搞清楚在做什么**

1. **Agent 到底是什么**：一条判据——下一步由谁决定。以及这条界线值多少钱、代价是什么；
2. **系统提示词**：Agent 的行为八成由它决定，比换模型有效得多；
3. **ReAct 与规划**：模型怎么做到"想一步、做一步、看结果再改主意"，以及四种翻车方式。

**第二部分：能力从哪来**

4. **工具与 MCP**：模型怎么真的动手——工具描述为什么就是提示词，工具多了会怎样；
5. **记忆与上下文**：模型本身没有记忆，所谓"记住"全是你存了再塞回去；
6. **检索与 RAG**：先找对，再让模型说话——检索错了会制造更可信的幻觉；
7. **上下文工程**：窗口有限，放什么进去、按什么顺序放。

**第三部分：往上搭之前想清楚**

8. **多智能体协作**：什么时候值得拆，什么时候是自找麻烦；
9. **框架选型**：那些框架到底替你做了什么，以及绑定的代价。

**第四部分：做成产品**

10. **流式与交互**：用户等不了三十秒——这是可用性前提，不是体验优化；
11. **成本与限流**：成本按"轮次 × 上下文"增长，是乘法不是加法；
12. **评测与上线**：怎么用可重复的方式判断它变好了，以及上线前的四道护栏；
13. **安全与护栏**：提示词不是权限——五道护栏按可靠性排序。

## 一条主线

这十三篇其实在讲同一件事：**Agent 的难点不在模型，在工程**。

模型负责"下一步大概该做什么"，剩下的全是你的责任——给它哪些工具、喂它哪些上下文、允许它走到第几步、出错时怎么兜底、花多少钱、怎么知道它做对了。这些没有一样是换个更大的模型就能自动解决的。

读的时候带着一个具体功能想：你希望它替谁做什么、失败了会怎样。这比记概念有用。

## 如果只有时间读三篇

读第 1、5、13 篇。

第 1 篇告诉你该不该用 Agent；第 5 篇解释为什么它会"忘事"、为什么越用越贵；第 13 篇告诉你上线前必须装哪几道闸。其余的都是在这三件之外做加法。

## 延伸阅读

本线的选题与章节划分参考了 Datawhale 的开源教程 [hello-agents](https://github.com/datawhalechina/hello-agents)（《从零开始构建智能体》，CC BY-NC-SA 4.0）。那是一本 16 章的完整教材，覆盖了本线没展开的部分：低代码平台实操、从零实现一个 Agent 框架、Agentic RL 训练（SFT 到 GRPO）、多智能体综合案例。

本线正文为独立撰写，不复述其内容；两边的详略取舍不同——它偏"完整教学"，本线偏"接功能前必须先想清楚的那几件事"。
