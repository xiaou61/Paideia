## 先把结论摆出来

**进程是资源单位，线程是调度单位。**

- 进程拥有自己的地址空间、打开的文件、环境变量、权限身份。进程之间默认谁也看不见谁。
- 线程是进程里的执行流。同一进程的线程**共享地址空间和文件描述符**，只各自持有栈、寄存器、程序计数器。

一句话：**进程是"一个隔离的容器"，线程是"容器里的工人"。** 容器隔离，工人共享。

这个区分能直接回答三类日常问题：为什么一个线程崩了整个进程都会死、为什么多线程改同一个变量会出错、为什么开一千个进程比开一千个线程贵得多。

## 进程里到底装了什么

启动一个进程时，内核给它准备的东西大致是：

- **虚拟地址空间**：代码段、全局数据、堆、栈（每个线程有独立栈）；
- **文件描述符表**：打开了哪些文件、socket、管道；
- **信号处理表**：收到 Ctrl+C 该怎么办；
- **身份**：用户、权限、所属命名空间。

这些东西的创建和销毁都不便宜。所以"每个请求开一个进程"在请求量上千时会先被创建开销拖垮，而不是被计算拖垮。

## 线程共享了什么，又独占了什么

同一进程内的线程：

| 共享 | 独占 |
| --- | --- |
| 堆上的对象、全局变量 | 自己的栈与局部变量 |
| 打开的文件与 socket | 寄存器与程序计数器 |
| 静态变量、代码段 | 线程本地存储（TLS） |

这张表解释了两件事：

1. **共享堆 → 需要同步**。两个线程同时 `count++`，读-改-写三步可能交错，结果少加了一次。
2. **栈独立 → 局部变量默认安全**。方法里的局部变量不会被别的线程碰——前提是没把它的引用传出去。

## 上下文切换：看不见的成本

CPU 同一时刻只在跑一个线程。要换线程，就得把当前线程的寄存器、栈指针存起来，再恢复另一个线程的。这叫上下文切换。

代价有三块：

- 切换本身的内核开销（几微秒，频繁时非常可观）；
- **缓存失效**：新线程的数据不在 L1/L2 里，要重新从内存拉；
- TLB 失效（跨进程切换时更明显）。

所以"线程越多吞吐越高"不成立。线程数远超核数时，CPU 有相当一部分时间在切换而不是在计算——表现是 `top` 里 `sy`（系统态）占比高，而业务吞吐没涨。

## 线程崩了为什么整个进程死

线程没有独立地址空间。一个线程写坏了堆上的对象，别的线程读到的是同一块坏数据；一个线程触发未捕获异常，JVM/解释器会结束整个进程（Java 里 `Thread` 的未捕获异常默认打印栈并终止该线程，但共享状态已经可能被破坏）。

要"一个任务崩了不影响别的任务"，就得用**进程隔离**——这也是浏览器一个标签页一个进程、网关按进程/容器隔离工作负载的原因。

## 怎么选：进程还是线程

| 场景 | 选择 | 理由 |
| --- | --- | --- |
| 大量 I/O 等待（请求、读写） | 线程 / 协程 | 共享地址空间，切换比进程便宜 |
| CPU 重计算 | 多进程 | 绕开 GIL/单线程限制，真并行 |
| 需要故障隔离 | 多进程 | 一个崩了不连累别人 |
| 需要共享大量数据 | 线程 | 进程间共享要序列化或共享内存 |

**判断顺序**：先问"会不会崩"（要隔离就进程），再问"在算还是在等"（在等用线程/协程，在算用进程），最后问"数据大不大"（大就避免跨进程复制）。

## 动手看一下

在 Linux 上随便找一个 Java 或 Python 进程：

```bash
ps -eLf | grep java        # 看一个进程下有几个线程（LWP 列）
top -H -p <pid>            # 按线程看 CPU，哪个线程在烧
```

看到"一个进程、几十个线程、只有一个线程占满 CPU"是常态：线程在等 I/O 时不占 CPU。

## 常见误区

### 误区：线程比进程"轻"，所以线程总是更好

**你以为**：线程创建快，能开就用线程。
**其实**：线程轻在创建，重在同居——共享状态带来的同步、竞态、调试成本都要算进去。需要隔离时，进程的"重"是买保险。
**怎么验证**：写一个多线程累加器不加锁，跑一万次看结果是否稳定偏小。

### 误区：进程之间完全不能共享数据

**你以为**：只能靠网络或文件。
**其实**：还有管道、共享内存、内存映射文件。共享内存最快，但要自己处理同步，等于把线程的麻烦搬到进程间。

### 误区：CPU 100% 就是程序在拼命干活

**你以为**：占用高代表计算多。
**其实**：可能是忙等（自旋锁）、GC、上下文切换、或死循环。看 `sy` 与 `us` 的比值、看线程栈，比看总占用有用。

## 小结

进程是隔离容器，线程是容器里的执行流。共享堆所以要同步，独立栈所以局部变量安全。切换有缓存成本，线程不是越多越好。要隔离用进程，要共享用线程。下一课讲每个进程都以为自己独占内存的那层幻觉：虚拟内存。
