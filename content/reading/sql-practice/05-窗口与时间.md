**目标**：用窗口函数在一行里同时拿到「明细」与「排名」

## 第 2 题 · 按天统计下单数

**目标**：datetime 列要先取日期再分组，否则每条都自成一「天」

```sql-challenge
{
 "id": "sql-p5-daily",
 "kind": "sql-write",
 "title": "按天统计下单数",
 "goal": "datetime 列要先取日期再分组，否则每条都自成一「天」",
 "dataset": [
  "orders-hidden-a",
  "orders-public"
 ],
 "starter": "SELECT ? AS day, COUNT(*) AS orders\nFROM orders\nGROUP BY ?\nORDER BY day\n",
 "normalize": {
  "rowOrder": "strict",
  "columnOrder": "ignore"
 },
 "expectHash": {
  "orders-hidden-a": "abfdbe2a80663c523e4c2f611840ec6898412dad2925cfc6a58cdab067e5d9a4",
  "orders-public": "ef661704a1c1c58dba55f7013847e290cb588525a10a42839bbf40bf191ae971"
 },
 "explain": "`created` 是 DATETIME，带时分秒。直接 GROUP BY 等于按「精确时刻」分组，几乎每条都单独成组；不写 GROUP BY 又只有一个总数。日报表的正确粒度是先截到「天」再聚合。"
}
```

**为什么**：`created` 是 DATETIME，带时分秒。直接 GROUP BY 等于按「精确时刻」分组，几乎每条都单独成组；不写 GROUP BY 又只有一个总数。日报表的正确粒度是先截到「天」再聚合。
