## 第 2 题 · 卖得最多的商品是哪个（按件数）

**目标**：分组求和后排序取第一名，并且写清并列时怎么定

```sql-challenge
{
 "id": "sql-p2-top",
 "kind": "sql-write",
 "title": "卖得最多的商品是哪个（按件数）",
 "goal": "分组求和后排序取第一名，并且写清并列时怎么定",
 "dataset": [
  "orders-hidden-a",
  "orders-public"
 ],
 "starter": "SELECT product\nFROM order_items\nGROUP BY ?\n-- 按什么排、怎么截断，你来补\n",
 "normalize": {
  "rowOrder": "ignore",
  "columnOrder": "ignore"
 },
 "expectHash": {
  "orders-hidden-a": "45e81bfdebc39f5dcdd1582421f15de4f5f7110a47992a7b2aa392ff3c93cf5e",
  "orders-public": "63bfb556cefccf3bb10428e437753cecbb28e067da4e93adf3f3ac6f9e167e0c"
 },
 "explain": "「卖得多」是件数，不是金额，也不是单笔最大。`ORDER BY qty DESC LIMIT 1` 只看了某一行；必须先在商品粒度上 SUM(qty)。并列时加第二排序键，结果才稳定——否则同样的查询两次可能给出不同答案。"
}
```

**为什么**：「卖得多」是件数，不是金额，也不是单笔最大。`ORDER BY qty DESC LIMIT 1` 只看了某一行；必须先在商品粒度上 SUM(qty)。并列时加第二排序键，结果才稳定——否则同样的查询两次可能给出不同答案。
