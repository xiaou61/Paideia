## 这一关要练什么

两种「空」的区别，以及一单没下的客户怎么还能留在结果里。

下面每题都在同一套订单数据上跑。写完点「运行」看结果对不对；**写错不扣分，可以一直试**。

## 第 2 题 · 每个客户下了几单，一单没下的也要列出来

**目标**：用 LEFT JOIN 保留没有匹配行的主表记录，COUNT(列) 只数非 NULL

```sql-challenge
{
 "id": "sql-p1-zero",
 "kind": "sql-write",
 "title": "每个客户下了几单，一单没下的也要列出来",
 "goal": "用 LEFT JOIN 保留没有匹配行的主表记录，COUNT(列) 只数非 NULL",
 "dataset": [
  "orders-hidden-a",
  "orders-public"
 ],
 "starter": "SELECT c.name, ? AS order_count\nFROM customers c\n-- 想想：一单没下的客户怎么还能留在结果里\n",
 "normalize": {
  "rowOrder": "ignore",
  "columnOrder": "ignore"
 },
 "expectHash": {
  "orders-hidden-a": "456eec316bd062789f6b8e18d18a5dc1243af9092c0957c4c631414aba9f090d",
  "orders-public": "df79464ba3819b1a51f445d113713d1445767b96354a8b68fc14490f9c21f65e"
 },
 "explain": "一单没下的客户在 orders 里没有任何行，内连接会把它整条丢掉。LEFT JOIN 保留左边，缺的右边补 NULL，COUNT(o.id) 不数 NULL，于是得到 0。注意不能写 COUNT(*)：那会把「补出来的那一行」也数成 1。"
}
```

**为什么**：一单没下的客户在 orders 里没有任何行，内连接会把它整条丢掉。LEFT JOIN 保留左边，缺的右边补 NULL，COUNT(o.id) 不数 NULL，于是得到 0。注意不能写 COUNT(*)：那会把「补出来的那一行」也数成 1。
