## 这一关要做什么

从标准输入读 `城市,金额`，按城市汇总，输出：

```text
<城市> <总额>
```

规则：

- 有效行：恰好两列，金额是非负整数；其余跳过；
- 每个城市一行，按**总额降序**；总额相同时按**城市名升序**；
- 没有有效行时什么都不输出。

## 先想清楚

这一关把前几关的技能叠在一起：**清洗 → 分组 → 排序 → 输出**。顺序不能乱：

1. 先过滤，坏行不参与任何计算；
2. 再分组累加；
3. 最后排序并打印。

排序同样有两条规则，少了第二条，同额城市的顺序就不稳定。

```python
groups = {}
for line in sys.stdin:
    parts = line.strip().split(',')
    if len(parts) != 2:
        continue
    city, raw = parts[0].strip(), parts[1].strip()
    try:
        amount = int(raw)
    except ValueError:
        continue
    if not city or amount < 0:
        continue
    groups[city] = groups.get(city, 0) + amount

for city, total in sorted(groups.items(), key=lambda kv: (-kv[1], kv[0])):
    print(f'{city} {total}')
```

## 常见误区

### 误区：先累加再过滤

**你以为**：先算完，最后把非法城市去掉。
**其实**：非法行一旦参与累加，总额就错了；过滤必须发生在分组之前。
**怎么验证**：输入里放一行 `shanghai,x`，看总额有没有被影响（应该没有）。

### 误区：城市名不 strip

**你以为**：CSV 里的值总是干净的。
**其实**：`" beijing"` 与 `"beijing"` 会分成两个城市，报告里出现两行看起来一样的名字。
**怎么验证**：输入 `" beijing ,10"`，看输出城市名前面是否带空格。

### 误区：同额城市顺序无所谓

**你以为**：反正金额一样。
**其实**：用例逐字比对，下游脚本也可能按行取前 N。**输出顺序是契约**，同额时必须再定一个键。
**怎么验证**：多跑几次同一输入，看顺序是否变化。
