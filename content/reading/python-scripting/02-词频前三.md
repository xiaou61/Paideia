## 这一关要做什么

从标准输入读单词（每行一个），统计出现次数，输出出现最多的前三个：

```text
word count
```

规则：

- 空行跳过，单词前后空白去掉，统一转小写；
- 排序：**次数降序；次数相同时按单词字母升序**；
- 不足三个就输出现有的；一个都没有就什么都不输出。

打个比方：排行榜要先比分数、分数相同再按名字排，规则不写全，同分的人每次站的位置都可能换。真实机制是：`sorted` 的 key 用一个元组同时表达“次数降序”和“字母升序”。

## 先想清楚

排序规则是这一关的核心。只按次数排，同次数的顺序取决于字典/插入顺序，**每次跑可能不一样**——脚本的输出是给机器比的，必须稳定。

```python
counts = {}
for line in sys.stdin:
    word = line.strip().lower()
    if word:
        counts[word] = counts.get(word, 0) + 1

items = sorted(counts.items(), key=lambda kv: (-kv[1], kv[0]))
for word, count in items[:3]:
    print(f'{word} {count}')
```

`key=lambda kv: (-kv[1], kv[0])` 就是两条规则：先按次数取负（大的在前），再按单词升序。

## 常见误区

### 误区：`most_common(3)` 能满足两条排序规则

**你以为**：Counter 自带排序，直接用。
**其实**：`most_common` 只保证次数降序；同次数项的先后取决于插入顺序，不保证字母序。
**怎么验证**：输入 `b\na\nc\n`，看输出第一行是不是 `a`。

### 误区：`sorted(counts, key=counts.get)` 就行

**你以为**：按值排完就对了。
**其实**：这样是升序，而且同值顺序不稳定；应该 `reverse=True` 或用负号，并显式加第二排序键。
**怎么验证**：多次运行同一输入，看输出是否每次都一样。

### 误区：空输入应该输出提示

**你以为**：没数据时打印"暂无数据"更友好。
**其实**：对下游脚本来说，多出来的一行是错误数据。**没有结果就输出空**，把提示放在 stderr 或退出码里。
**怎么验证**：用例期望是空字符串；多打一行就 fail。
