**目标**：重写 `equals` 就必须重写 `hashCode`，否则哈希表找不到

 "language": "java",
 "starter": "import java.util.HashMap;\nimport java.util.Map;\n\npublic class Main {\n    static class Key {\n        private final String value;\n\n        Key(String value) {\n            this.value = value;\n        }\n\n        @Override\n        public boolean equals(Object other) {\n            return other instanceof Key key && key.value.equals(value);\n        }\n    }\n\n    public static void main(String[] args) {\n        Map<Key, String> map = new HashMap<>();\n        map.put(new Key(\"a\"), \"A\");\n        System.out.println(\"found=\" + map.get(new Key(\"a\")));\n    }\n}",
 "cases": [
  {
   "name": "正确输出",
   "expected": "found=A\n"
  }
 ],
 "explain": "`HashMap` 先按 `hashCode` 找桶，再用 `equals` 在桶里比。`Key` 重写了 `equals` 却没有 `hashCode`，两个\"内容相同\"的 key 落到不同桶，所以 `get` 找不到。**equals 与 hashCode 必须成对重写**（规则：equals 相等则 hashCode 必须相等）。用 `record` 可以自动生成两者。"

## 第 4 题 · 想删值 10，结果越界了

**目标**：`remove(int)` 删下标，`remove(Object)` 删元素，重载解析看的是参数类型

```code-challenge
{
 "id": "dbg-08-remove-overload",
 "kind": "run",
 "title": "想删值 10，结果越界了",
 "language": "java",
 "starter": "import java.util.ArrayList;\nimport java.util.List;\n\npublic class Main {\n    public static void main(String[] args) {\n        List<Integer> list = new ArrayList<>(List.of(5, 10, 20));\n        list.remove(10);\n        System.out.println(\"rest=\" + list);\n    }\n}",
 "cases": [
  {
   "name": "正确输出",
   "expected": "rest=[5, 20]\n"
  }
 ],
 "explain": "`List.remove` 有两个重载：`remove(int index)` 和 `remove(Object o)`。传字面量 `10` 会选 `int` 版本，删的是下标 10，列表只有 3 个元素，于是 `IndexOutOfBoundsException`。要删\"值为 10 的元素\"，得传对象：`remove(Integer.valueOf(10))`。这是重载解析最经典的坑。"
}
```

**为什么**：`List.remove` 有两个重载：`remove(int index)` 和 `remove(Object o)`。传字面量 `10` 会选 `int` 版本，删的是下标 10，列表只有 3 个元素，于是 `IndexOutOfBoundsException`。要删"值为 10 的元素"，得传对象：`remove(Integer.valueOf(10))`。这是重载解析最经典的坑。
