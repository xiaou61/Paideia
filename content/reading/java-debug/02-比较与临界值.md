## 这一关要练什么

字符串用 == 为什么永远不等；60 分到底算不算过。

每题给一段**能跑但结果是错的**代码与它应有的输出。改到输出一致就算过，改坏了可以接着改。

## 第 1 题 · 名字明明一样，判断却不成立

**目标**：字符串用 == 比的是「是不是同一个对象」，比内容要用 equals

```code-challenge

 "language": "java",
 "starter": "public class Main {\n    public static void main(String[] args) {\n        String role = String.join(\"\", \"ad\", \"min\");\n        if (role == \"admin\") {\n            System.out.println(\"welcome\");\n        } else {\n            System.out.println(\"denied\");\n        }\n    }\n}",
 "cases": [
  {
   "name": "正确输出",
   "expected": "welcome\n"
  }
 ],
 "explain": "`==` 比较两个引用是否指向同一个对象；`String.join` 拼出来的字符串在堆上，跟常量池里的字面量不是同一个对象，所以永远不等。用 `equals` 比内容。**方向也要注意**：写成 `role.equals(\"admin\")` 时，如果 role 是 null 会抛空指针；把常量放前面（`\"admin\".equals(role)`）就不会。"
}
```

**为什么**：`==` 比较两个引用是否指向同一个对象；`String.join` 拼出来的字符串在堆上，跟常量池里的字面量不是同一个对象，所以永远不等。用 `equals` 比内容。**方向也要注意**：写成 `role.equals("admin")` 时，如果 role 是 null 会抛空指针；把常量放前面（`"admin".equals(role)`）就不会。

## 第 2 题 · 刚好 60 分的人被判成不及格

**目标**：边界条件写 > 还是 >=，决定了临界值落在哪一边

```code-challenge
{
 "id": "dbg-04-off-by-one",
 "kind": "run",
 "title": "刚好 60 分的人被判成不及格",
 "language": "java",
 "starter": "public class Main {\n    public static void main(String[] args) {\n        int[] scores = {59, 60, 61};\n        for (int score : scores) {\n            String result = score > 60 ? \"pass\" : \"fail\";\n            System.out.println(score + \"=\" + result);\n        }\n    }\n}",
 "cases": [
  {
   "name": "正确输出",
   "expected": "59=fail\n60=pass\n61=pass\n"
  }
 ],
 "explain": "题目说「60 分及格」，那么 60 本身要算过，必须写 `>=`。`>` 与 `>=` 差一个字符，影响的是**恰好等于边界的那一个值**——测试数据里如果全是不挨着边界的数，这个 bug 永远不会暴露。所以边界值必须进测试数据：59、60、61 三个一起测。"
}
```

**为什么**：题目说「60 分及格」，那么 60 本身要算过，必须写 `>=`。`>` 与 `>=` 差一个字符，影响的是**恰好等于边界的那一个值**——测试数据里如果全是不挨着边界的数，这个 bug 永远不会暴露。所以边界值必须进测试数据：59、60、61 三个一起测。
