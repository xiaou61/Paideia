## 这一关要练什么

整数相除丢掉小数；循环条件差一位。

每题给一段**能跑但结果是错的**代码与它应有的输出。改到输出一致就算过，改坏了可以接着改。

## 第 1 题 · 平均分为什么少了一截

**目标**：整数相除会丢掉小数部分；想保留小数，至少让一边是浮点

```code-challenge

 "kind": "run",
 "title": "平均分为什么少了一截",
 "language": "java",
 "starter": "public class Main {\n    public static void main(String[] args) {\n        int[] scores = {91, 84, 77, 66};\n        int sum = 0;\n        for (int s : scores) {\n            sum += s;\n        }\n        double average = sum / scores.length;\n        System.out.println(\"average=\" + average);\n    }\n}",
 "cases": [
  {
   "name": "正确输出",
   "expected": "average=79.5\n"
  }
 ],
 "explain": "`sum / scores.length` 两边都是 int，除完已经是整数（79），再赋给 double 只是把 79 变成 79.0——小数部分在赋值之前就丢了。让任意一边是 double 才会做浮点除法。这类 bug 在金额、比率、平均值上最隐蔽：结果永远是个「看起来合理」的数。"
}
```

**为什么**：`sum / scores.length` 两边都是 int，除完已经是整数（79），再赋给 double 只是把 79 变成 79.0——小数部分在赋值之前就丢了。让任意一边是 double 才会做浮点除法。这类 bug 在金额、比率、平均值上最隐蔽：结果永远是个「看起来合理」的数。

## 第 2 题 · 遍历数组时越界

**目标**：数组下标的范围是 0 到 length-1，循环条件差一位就会抛异常

```code-challenge
{
 "id": "dbg-02-loop-bound",
 "kind": "run",
 "title": "遍历数组时越界",
 "language": "java",
 "starter": "public class Main {\n    public static void main(String[] args) {\n        int[] values = {3, 5, 8, 13};\n        int total = 0;\n        for (int i = 0; i <= values.length; i++) {\n            total += values[i];\n        }\n        System.out.println(\"total=\" + total);\n    }\n}",
 "cases": [
  {
   "name": "正确输出",
   "expected": "total=29\n"
  }
 ],
 "explain": "`i <= values.length` 会在 i 等于 length 时再进一次循环，而合法下标最大是 length-1。抛出的 `ArrayIndexOutOfBoundsException` 通常带行号，是这一类里最好查的；难查的是那种不报错、只是少加了一个元素的写法（比如 `i < values.length - 1`）。"
}
```

**为什么**：`i <= values.length` 会在 i 等于 length 时再进一次循环，而合法下标最大是 length-1。抛出的 `ArrayIndexOutOfBoundsException` 通常带行号，是这一类里最好查的；难查的是那种不报错、只是少加了一个元素的写法（比如 `i < values.length - 1`）。
