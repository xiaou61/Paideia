## 这一关在解决什么

图表不是装饰，是**论证的一部分**。同一份数据，换一种图、改一个坐标轴，读者会得出相反的结论。

这一关给两个判断：**该用什么图**、**什么样的图在骗人**。

打个比方：图表是给结论配的说明图，不是装饰画。真实机制是：图型由问题决定，坐标轴和口径决定读者看到什么。

## 讲解

### 先看问题是哪种

| 你要回答 | 用 | 不要用 |
| --- | --- | --- |
| 各类别的大小比较 | 横向条形图 | 饼图（类别多时） |
| 随时间变化 | 折线图 | 条形图（时间被当成离散类别） |
| 两个变量的关系 | 散点图 | 双轴折线（容易暗示因果） |
| 分布 | 直方图、箱线图 | 只用均值 |
| 构成（少量类别） | 堆叠条、饼图（≤5 类） | 堆叠面积（难读） |

选图的第一原则：**读者要在 3 秒内看出"谁大谁小、往哪走、有没有关系"**。做不到，就换图。

### 条形图从 0 开始，折线可以不

条形图的长度就是数值，截断纵轴会让 5% 的差异看起来像 5 倍——这是最经典的误导。

折线图比较的是**变化趋势**，不比较绝对长度，所以纵轴可以不从 0 开始；但必须在图注里写清楚范围。

```text
条形图：y 轴从 0 开始（硬规则）
折线图：y 轴可缩放，但要标注 min/max
```

### 双轴图：能不画就不画

一条线看订单量、一条线看转化率，左右两个 y 轴。两条线的交叉点、相对高低完全由两个轴的缩放决定，**没有任何含义**。但读者会本能地解读成"相关"。

如果两个指标量纲差很多，更安全的做法是：画两张小图（上下对齐、共享 x 轴），或者都转成"相对基期的指数"。

### 颜色与顺序也在传递信息

- 同一类别在两张图里用不同颜色，读者会以为是两个东西；
- 按数值排序的条形图比按字母序更好读；
- 强调一个类别时，其余用灰色，而不是给每个类别一个鲜艳颜色。

```python
colors = ['#d4d4d8'] * len(data)
colors[highlight] = '#2563eb'
```

### 图注比图本身更重要

一张合格的图至少写清：

1. **口径**：人群、时间范围、过滤条件；
2. **单位**：元/万元、人/人次；
3. **样本量**：小样本要标注，避免读者过度解读；
4. **来源**：哪张表、哪次取数。

没有这四项，图只能当插图，不能当证据。

### 常见的四种"说谎"方式

1. **截断坐标轴**：让微小差异看起来巨大；
2. **面积/3D 缩放**：把数值映射到半径而不是面积，视觉上放大平方；
3. **挑时间段**：从上升趋势里挑一段下降的区间；
4. **只画均值**：把双峰分布画成一条平稳的线，掩盖两个群体。

前两种是视觉误导，后两种是选择误导。后两种更危险，因为图本身完全"正确"。

## 常见误区

### 误区：图越漂亮越有说服力

**你以为**：加渐变、3D、阴影，报告更专业。
**其实**：装饰会占用视觉通道，让读者更难比较数值。专业图表的共同点是**信息密度高、装饰少**。
**怎么验证**：遮住标题，问同事"这张图想说明什么"；3 秒内答不出来，就该简化。

### 误区：饼图能显示所有占比

**你以为**：饼图最直观。
**其实**：超过 5 个类别，人眼无法比较扇区角度；相邻扇区大小接近时几乎不可读。类别多就用横向条形图，按大小排序。
**怎么验证**：把 8 个类别的饼图给三个人看，问"第三大是哪个"，答案经常不一致。

### 误区：双轴图能同时展示两个指标

**你以为**：一张图信息更多。
**其实**：两个 y 轴的相对缩放是任意的，线的交叉与分离没有意义，却会被读成关系。
**怎么验证**：把右轴范围改一倍，图里的"关系"立刻变了——说明它本来就不存在。
