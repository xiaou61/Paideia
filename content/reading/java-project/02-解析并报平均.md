## 这一关要做什么

真实项目里的输入总是不干净：空串、空白、非数字项、除零。

**目标**：把逗号分隔的数字串解析出来，输出 `avg=<整数平均>`；没有有效数字时输出 `avg=0`；输入为空时输出 `undefined`。

## 先修理论

用到第 4 课（字符串）、第 9 课（字符串方法）与第 13 课（异常）。核心只有两件事：`trim()` 去空白、`Integer.parseInt` 失败时接住异常。

## 怎么交

你的代码会被固定保存成 `Main.java`，**类名必须是 `Main`**。`TestMain.java` 只读，逐条打印 `ok:` / `fail:`。

| 输入 | 期望 |
| --- | --- |
| `""` 或只有空白 | `undefined` |
| `"5"` | `avg=5` |
| `" 1, 2 ,3 "` | `avg=2`（6 / 3） |
| `"2,x,4"` | `avg=3`（x 跳过） |
| `"a,b"` | `avg=0`（不是除零） |
