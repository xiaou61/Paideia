## 这一关要做什么

给一段英文文本，统计每个单词出现的次数，返回出现最多的 k 个单词。

```sketch
{
  "title": "词频：先数一遍，再取前 k",
  "rows": [
    [
      { "id": "count", "title": "遍历数一遍", "sub": "HashMap 计数", "tone": "gray" },
      { "id": "heap", "title": "小顶堆取 top-k", "sub": "O(n log k)", "tone": "blue" },
      { "id": "tie", "title": "并列时按什么排", "sub": "口径要写进注释", "tone": "amber" }
    ]
  ],
  "arrows": [
    { "from": "count", "to": "heap" },
    { "from": "heap", "to": "tie" }
  ]
}
```

规则（测试按这四条判）：

1. 只把**字母**当单词的一部分，空格、标点、数字都当分隔符；统一转小写；
2. 按出现次数从多到少排；
3. 次数相同按字母顺序；
4. 空文本或 `k <= 0` 返回空列表；k 超过不同单词数时返回全部。

## 先修理论

第 8 课（Map）、第 11 课（equals 与 hashCode）、第 12 课（集合选型）、第 20 课（Stream 与排序）。这一关考的不是语法，而是**两条排序规则的主次**。
