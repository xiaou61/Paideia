## 这一关要读什么

MyBatis 2.1 万行，但它的调用链只有一条主干。这一关不加细节，先把主干摆出来：

**你写的 Mapper 接口 → 一个代理对象 → Executor → StatementHandler → JDBC → 结果集。**

后面 23 关都在往这条主干上挂细节。先有地图，细节才不会散。

## 一次查询会经过谁

1. `sqlSession.getMapper(UserMapper.class)`：拿到的不是你的实现，是**JDK 动态代理**。
2. 调 `userMapper.selectById(1)`：代理拦下来，交给 `MapperMethod`。
3. `MapperMethod` 把「方法 + 参数」翻译成「语句 id + 参数」，交给 `SqlSession`。
4. `SqlSession` 找到 `Executor`（默认 `SimpleExecutor`，可被缓存装饰）。
5. `Executor` 让 `StatementHandler` 造 `PreparedStatement`、绑参数。
6. `ResultSetHandler` 把结果集映射成对象，一路返回。
